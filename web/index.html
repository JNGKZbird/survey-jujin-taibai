边界

Work 模式支持读表、填表、审批、撤销与联网搜索；Chat 模式不读写表格，只用联网搜索。两种模式都可以发送记录表图片：Work 可据此填表，Chat 只做问答。联网搜索在两种模式下都只走 DeepSeek 官方地址，不抓取网页正文。

隐私

无遥测、无账号、无云端同步。对话请求发往你填写的 Base URL。联网搜索固定发往 api.deepseek.com，发送搜索词并沿用当前 DeepSeek Key；搜索结果是外部不可信内容。应用不会自动抓取或打开网页，只有点击来源时才用系统浏览器打开。agent.json 只保存来源的标题、链接、站点与日期，不保存摘要或正文。图片会随对话请求发送到 Base URL 站点；服务商可能按其隐私政策保存或处理。发送前会在本机压缩并去掉 EXIF；压缩后的完整图片会保存在本机应用数据目录的 attachments，文件未加密；相机原始文件不保存。agent.json 只保存小缩略图与转写文字，文件同样未加密。
