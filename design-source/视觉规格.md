## 7. 给 Code Agent 的叠框说明

### 7.1 推荐做法（百分比定位）

```css
.sheet-wrap{ position:relative; width:100%; max-width:1600px; aspect-ratio: 1674 / 1147.8; }
.sheet-wrap > svg{ position:absolute; inset:0; width:100%; height:100%; display:block; }
.sheet-wrap .cell-input{ position:absolute; box-sizing:border-box; }
```

```html
<!-- 例：1 站 1 行 水平度盘读数 -->
<input class="cell-input" style="left:23.32%;top:23.56%;width:9.68%;height:4.27%">
```

`left/top/width/height` 直接取 `geometry.json` 的 `px / py / pw / ph`（已按 viewBox 折算成百分比）。

### 7.2 硬约束

1. **不要**把输入框铺满格子：`geometry.json` 的框已按格线内缩 2.5 单位，压线会在缩放时"吃线"。
2. 斜线格（测站/仪器高、目标/棱镜高）只给了三角内接矩形；若要做"标签 + 值"两行，请**不要超出该矩形**（否则跨斜线）。
3. 水平角值的 `L / 平均值 / R` 是**印刷静态标签**，输入框必须落在 `s{i}-angle-l/-avg/-r` 的框内（已在标签右侧留出宽度）。
4. `s{i}-angle` 是整块容器，只用来画底/取 bbox，**不要**在上面放输入。
5. 数值字号建议 13–15 px @1600；行高 54 单位 ≈ 51.6 px，容得下 30–34 px 的输入框；`s{i}-r{j}-h` 等格高度 49 单位 ≈ 47 px 足够。
6. 打印：整体宽度按 260 mm 计，A4 横向可放下；线宽在打印时不要加粗（保持矢量 scale）。
7. SVG 的 `<style>` 已全部限定在 `#sheet` 下，内联进页面**不会污染**页面其它 `text` 样式；但请保留 `id="sheet"` 这个祖先节点。

### 7.3 字体加载

页面里已有 `assets/fonts/HarmonyOS_Sans_SC_*.woff2`，请用 `@font-face` 注册为 **`HarmonyOS Sans SC`**（与 SVG 内字体栈同名），SVG 内文字即自动命中；未加载时回落到 `Microsoft YaHei / SimHei`，版式不变（字宽略差 1–3 px）。

## 9. 关于"1 单位 = 0.158 mm"的前提

照片里纸张边缘被裁掉，无法直接读物理尺寸，故按以下两点交叉校核：

1. **方块字校准**：表头单字墨迹 23×23、23×24 px，长宽比 0.96–1.04（中位数 ≈ 1.00），说明校正后纵横比例误差 < 2 %。
2. **字号自洽**：若表宽取 260 mm（A4 横向 297 − 2×18.5 边距），换算 6.32 px/mm，则正文字号恰为 12 pt、标题 18 pt（都是中文排版标准字号）；取其它比例会得到 11.4 pt / 12.6 pt 这类非标值。

若后续确认纸张/表格实际宽度不同，**只改 `viewBox` 的物理换算说明即可**，SVG 内几何（比例）无需改动。
