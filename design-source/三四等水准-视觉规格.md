## 6. 语义 ID（`geometry.json` 共 239 条）

命名：表头 `h-*`；数据 `s{站 1–8}-r{行 1–4}-{键}`；整列合并 `s{i}-remark` / `remark`。

| 类别 | ID 形式 | 数量 | 角色 |
|---|---|---|---|
| 表头信息 | `meta-date` `meta-weather` `meta-instrument` `meta-class` `meta-group` | 5 | input |
| 表头静态 | `h-observers` `h-station-no` `h-back-ruler` `h-back-lower` `h-back-upper` `h-front-ruler` `h-front-lower` `h-front-upper` `h-back-dist` `h-front-dist` `h-dist-diff` `h-sum-d` `h-direction` `h-staff-read` `h-black` `h-red` `h-k-diff` `h-mean-height` `h-remark` | 19 | static |
| 测站编号格 | `s{i}-station-no`（i=2…8）、`s{i}-observers` | 14 | input / static |
| 量测录入 | `s{i}-r{j}-back` `…-front`（j=1…4）、`…-dir` `…-black` `…-red`（j=1…3）、`s{i}-r4-wide` | 8×(8+6+1)=120 | input |
| 计算值 | `s{i}-r{j}-k` `…-mean`（j=1…3） | 48 | computed |
| 整列合并 | `s{i}-remark`（每站备注重叠区）、`remark`（整列 771→1530 的合并格） | 9 | input |

- SVG 内每个语义格都对应一个 `<rect id="{id}-box">`（`fill:none; stroke:none; pointer-events:none`），可直接 `getBBox()`；印刷文字另有 `-glyph`/`-1`/`-2` 后缀的 `id`。
- `role`：`input`（录入）/`computed`（算值）/`static`（印刷字形，避让）/`meta`（表头信息）。

## 7. 给 Code Agent 的叠框说明

```css
.wrap{ position:relative; width:100%; max-width:1036px; aspect-ratio:1036 / 1637; }
.wrap > svg{ position:absolute; inset:0; width:100%; height:100%; }
.wrap .cell{ position:absolute; box-sizing:border-box; }
```

```html
<input class="cell" data-cell="s1-r1-back" style="left:18.05%;top:18.11%;width:11.97%;height:2.11%">
```

- `left/top/width/height` 取 `geometry.json` 的 `px/py/pw/ph`（百分比）。
- 框已内缩 2 单位，**不要再铺满整格**，否则缩放时压线。
- 左两列（`h-observers` / `h-station-no`）是静态竖排文字，只能在其下方空白处放输入。
- 第 4 行右侧是**一格横向合并**（`s{i}-r4-wide`），不要按 4 列拆。
- `备注` 整列是一格（`remark`，从 294.44 到 1530），每站的 `s{i}-remark` 只是同一格的视觉分段，二选一使用，不要同时放输入。
- 数值字号建议 13–15 px @1036；行高 38.6 px，输入框高 ≤ 34 px。
- `#sheet` 作用域已把样式限制在 SVG 内部，内联进页面不会污染其它元素；请保留 `id="sheet"`。
