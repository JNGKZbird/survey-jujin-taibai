### 7.1 表头信息（6 个可录入区）

`meta-date`、`meta-instrument`、`meta-observer`、`meta-weather`、`meta-group`、`meta-recorder`

| ID | 角色 | 跨行 | 说明 |
|---|---|---|---|
| `s{i}-station` | input | 4 | 测站号 |
| `s{i}-face-left` | static | 2 | 印刷「左」字，避让 |
| `s{i}-face-right` | static | 2 | 印刷「右」字，避让 |
| `s{i}-half-left` | computed | 2 | 左盘半测回角值 |
| `s{i}-half-right` | computed | 2 | 右盘半测回角值 |
| `s{i}-halfdiff` | computed | 4 | 半测回角值之差 |
| `s{i}-angle` | computed | 4 | 一测回角值 |
| `s{i}-sketch` | free | 4 | 角度草图（手绘/线稿） |
| `s{i}-dist-err` | free | 4 | 距离及相对误差 |
| `s{i}-r{j}-target` | input | 1 | 行 j 的目标（j = 1…4） |

- `input`：直接录入；

## 9. 叠框说明（对 Code Agent）

1. **容器**
   ```css
   .sheet-wrap { position: relative; width: 100%; aspect-ratio: 1248 / 1490; }
   .sheet-wrap > svg { position: absolute; inset: 0; width: 100%; height: 100%; display: block; }
   ```
   容器宽度即显示宽度；1248 px 为 1:1 推荐值。
2. **定位**：每个输入框用 `geometry.json` 的 `px/py/pw/ph` 百分比定位，绝对定位在 `.sheet-wrap` 内。**不要**用固定 px 定位，否则缩放会漂。
3. **内缩**：数据格的 `x/y/w/h` 已贴着网格线（线宽 1.2，中心在格边上）。建议输入框再向内缩 **2–3 单位**（1248 宽时约 2–3 px；百分比约 0.16–0.24%），避免压线。
4. **单位格**
   - 度盘读数：建议 3 个子输入（度/分/秒），沿格子宽度分成 3 段，或用 1 个输入 + 蒙版显示 `° ′ ″`；印刷单位符号在格子上半部，输入行应在其**下方**（基线 54.5 以下）。
   - 一测回角值：1 行 4 行高的合并格，建议 3 组数字垂直居中。
5. **合并格**
   - `s{i}-half-left/right`：2 行高，单值垂直居中。
   - `s{i}-halfdiff`、`s{i}-angle`、`s{i}-dist-err`：4 行高，单值或演算，垂直居中。
   - `s{i}-sketch`：4 行高，留空或放小型 SVG 草图；**不要**加输入框边框。
6. **静态避让**：`s{i}-face-left/right` 是印刷字，若把输入框做成整个盘位格，请把文字设为 `pointer-events:none` 并降低视觉权重，或在字的下方留出书写区。
7. **表头信息**：6 个 `meta-*` 框是「下划线上方」的 24 高空白；值应基线对齐到下划线上方 3 单位（`static_texts.meta_rows.baseline`）。
8. **字号**：输入文字建议 19–20 px（@1248），用同一宋体栈；颜色 `#111`，不要加粗。
9. **打印/截图**：SVG 是纯矢量，透明底；页面若要纸张色，请由容器背景提供，不要给 SVG 加底。

## 10. 哪些是量出来的、哪些是推断的

| 项 | 做法 | 可信度 / 影响 |
|---|---|---|
| 表格四点、透视 | 外框四边逐像素拟合后求交，单应校正 | 边线拟合残差中位 < 0.6 px；纸张弯曲使局部达 5–8 px，已由理想化吸收 |
| 列边界 | 全高逐线拟合二次曲线后取均值 | 均值误差 < 1 单位；照片弯曲造成 ±4 px 局部漂移 |
| 行边界 | 25 条横线逐块检测 | 实测 49.3–51.2，取 50.18 统一，累计 < 2.5 单位 |
| 合并关系 | 对每条网格线段做「存在/不存在」检测 | 已逐段验证，见 §4 |
| 字号 | 汉字墨迹高 + 字距推算 | ±0.5 单位 |
| 线宽 | 垂直于线的灰度截面 FWHM，含墨迹扩散补偿 | ±0.2 单位 |
| 纵横比 | 先把外框校正成正方形，再量汉字墨迹长宽比 ≈ 1.06，故 y×1.06 | 若真实字形比 1.00 更扁/更宽，纵横比会差 1–2% |
| 物理尺寸 | 按 A4 估算 | ±5%，不影响比例 |
| 标题水平位置 | 照片上标题中心比表格中心偏左约 10 单位（纸张弯曲/印刷偏移） | 已按**几何居中**理想化；若要求严格照印，可左移 10 |
| 字体 | 照片是宋体；用 SimSun 栈 | 字形骨架一致，笔画锐度不同（矢量 vs 印刷墨迹） |

3. **测站格**：照片上测站格是空白（手写），确认不需要印刷「测站 1…6」。
4. **角度草图**：确认是手绘区，不需要预置图形。
5. **表头信息**：下划线是印刷线（照片上有），已画成静态线；若页面要叠输入框，按 §9.7 处理。
6. **标题偏移**：若用户希望严格复刻照片的 10 单位左偏，改 `static_texts.title.x` 为 590 即可。

## 11. 与照片的对照结论

- 结构：10 列 ×（表头 + 6 站 × 4 行）= 完整；所有合并、单位、下划线、说明文字齐备。
- 叠图：网格线偏差中位 ≤ 1.7 px（@1248），最大 4.0 px（纸张弯曲处）；文字偏差 2–5 px；标题因居中化偏 +10 px。
- 细节差异：照片的墨迹更粗（印刷+JPEG 扩散），SVG 为干净矢量，观感略轻；这是「印刷表单」而不是「照片复刻」的预期差异。
- 没有带入：夹板、尺子、桌面、阴影、纸张弯曲、背面透印、页码「1」、页面外框、JPEG 噪点、任何手写/示例数据。
