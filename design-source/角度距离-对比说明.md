# 对比说明 · 角度距离观测记录手簿

> 对象：`角度距离-记录手簿.svg` ↔ 本地原照片（1856×2476，未修改；未随仓库提供）
> 附件：`角度距离-并排对比.png`（左照片 / 右 SVG）、`角度距离-叠图.png`（红=照片、绿=SVG、重叠≈黑）

---

## 1. 原图与透视校正

照片是桌面斜拍：纸张有透视、纵向弯曲，夹板、钢尺、桌面、阴影入镜，纸张背面还有透印（右下角可见镜像文字和淡格子）。

**校正步骤**

1. 在原图上逐像素拟合表格外框的四条边（对每条边采样、RANSAC 去离群、最小二乘求线），求交得到四角：

   | 角 | 原图像素 (x, y) |
   |---|---|
   | 左上 TL | (125.0, 284.8) |
   | 右上 TR | (1683.7, 328.0) |
   | 右下 BR | (1794.5, 2119.5) |
   | 左下 BL | (10.4, 2142.6) |

2. 以单应变换把外框映射到矩形画布，消除透视。外框四边在照片上有 ±5 px 的弯曲（纸张卷曲），单应只能取直，剩余弯曲进入 §3 的残差。
3. **纵横比标定**：先把外框映射成 2400×2400 正方形，量汉字墨迹（盘、位、度、读、数、标、距、离…）的长宽比，中位数 ≈ **1.06**（偏宽）。把纵向目标改为 `2400 × 1.06 = 2544`，汉字回到 ≈1.00。因此还原表的纵横比为 `1200 : 1272 = 0.9434`。
4. 在 2400×2544 校正图上逐线量测（竖线 11 条、横线 25 条），按"某段线上有墨/无墨"判定合并关系，再按比例输出到 1248×1490 的 SVG 画布。

第 3 步的 6% 是本次还原**唯一的自由参数**；它无法从照片单独证明，只能由"印刷汉字应为方块"这一先验推出。若日后有实尺，可再标定一次。

## 3. 残余偏差（叠图实测）

在 1248 px 宽的校正照片与 SVG 渲染之间，用同一条扫描线测网格线中心：

| 检查位置 | 竖向网格线偏差（中位 / 最大） | 横向网格线偏差（中位 / 最大） |
|---|---|---|
| 表头 + 第 1 站 | 1.0 / 3.0 px | 1.5 / 4.9 px |
| 表中部 | 1.0 / 1.7 px | 1.0 / 3.5 px |
| 表下部 | 1.3 / 3.2 px | 0.8 / 2.6 px |

- 相对表宽 1200 px：最大 **0.4 %**，中位 **0.12 %**。
- 偏差主要来自纸张卷曲：照片上的竖线/横线是弓形，SVG 是直线；在表格四角最大，中间最小。
- 文字：`左/右`、表头文字与照片墨迹框相差 2–5 px；标题因**几何居中化**比照片右移约 10 px（照片上标题中心比表格中心偏左约 10 单位，判断为拍摄/纸张弯曲造成的偏移，未复刻）。
- 线宽：SVG 的外框/内线灰度截面的半高宽与照片一致（±0.3 px），但照片有印刷墨迹扩散，视觉上更"糊"、更重；SVG 是干净矢量，这是预期差异。

## 4. 图怎么读

`角度距离-叠图.png`

- **红** = 照片（透视校正后，灰度反相后进 R 通道）
- **绿** = SVG 渲染（进 G 通道）
- **黑** = 两者都黑（重合）
- 底部有图例条；整图按表格区域 1:1 对齐，宽 1248 px。

`角度距离-并排对比.png`

- 左：校正后的照片（自动对比度，保留纸张灰度）；
- 右：SVG 在 1248 px 宽的渲染；
- 两块都缩放到 860 px 宽以便同屏比较。

## 5. 排除了什么（没有带进 SVG）

| 排除项 | 原因 |
|---|---|
| 夹板、钢尺、桌面、手、阴影、高光 | 表格外的环境，不属于印刷表 |
| 透视、纸张弯曲、折痕、纸纹 | 只还原正面、平整、理想化几何 |
| 背面透印（淡格子、镜像的"使用铅笔记录…"） | 不是正面印刷内容 |
| 右下角页码「1」 | 装订/页码痕迹，不属于表格 |
| 页面外框淡线（表格外 10 mm 左右） | 页面裁切/装订参考线，不属于表格 |
| JPEG 噪点、压缩色斑 | 扫描噪声 |
| 任何手写、示例数字 | 原表是空白印刷模板 |

## 6. 结论

- **结构**：10 列；表头 1 行 + 6 个测站块 × 4 行 = 24 数据行；每块 左×2 行、右×2 行；半测回角值按盘位跨 2 行；半测回角值之差 / 一测回角值 / 角度草图 / 距离及相对误差 各跨 4 行；目标、度盘读数、距离(m) 每行一格。与照片逐段核对一致。
- **文字**：标题、2 行表头信息（日期/仪器/观测、天气/班组/记录）、10 个列头（含 3 组 ° ′ ″）、12 个左/右、底部说明，位置与字号均在 ±5 px 内（标题居中化除外）。
- **偏差**：网格线 ≤ 0.4 % 表宽，主要来自纸张卷曲；无结构性偏差。
- **可调**：所有坐标在 `角度距离-geometry.json`；若用户指出某一列/行/字偏差，可直接改数值重渲染，不影响其它部分。
