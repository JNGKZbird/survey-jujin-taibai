# 表G：导线计算表（第七张表）

表G「导线计算表」是项目里的第七张表，也是**当前项目表一与表六的联合带入**：**一条导线可以跨页**——第 1 页是开始页，第 2 页起可以标成「接续」，承接导线第 12、23… 站；角度闭合差、改正数、方位角与坐标跨页统一计算。点号、内角、导线长从本项目的表一取（内角按表四口径、边长取往返平距平均值），高程列可选从表六取；**表一的数据是根基**。

- 可编辑的只有表头 4 项、每页 11 行的点号 / 内角 / 导线长 / 高程，以及开始页首行的 X / Y / 起算方位角；续页首行的 X / Y / 方位角由上一页推算，其余计算列全部由引擎推算。
- 每页固定 11 行，不随数据增减；一条导线由一张开始页和紧跟其后的若干续页组成，连续的续页属于它前面最近的开始页。要另算一条导线，在抽屉里把某一页切成「独立导线」。
- 带入时按表一已开始站数自动分页，重写整条导线：站数变多会补续页，变少会删多余的续页（删除前确认）。
- 带入后的行落在纸上，可以继续手改。这一点与表四～表六「每次渲染重算」不同：表G 是带入式，重新带入会覆盖整条导线（先确认）。
- 首行的 X / Y / 起算方位角可以由 P/T 起算坐标与表四表头的连接角 β1、β2、连接边 d 解算后一键填入，见「起算数据解算」。
- 屏幕右上有一张「计算摘要」卡，按整条导线算、每页都显示，只显示、不打印；点开进入检查面板。
- 表G 不参与表一 ↔ 表三联立，选项抽屉里没有联立段。

对应纯计算模块是 `web/assets/calc-traverse-calc.js`（不碰 DOM）。单页入口是 `compute(page)`，跨页入口是 `computePages(pages, settings)`；表格尺寸、输入格与计算格在 `web/assets/app.js` 的 `TABLES` / `PAPER` 与 `buildTraverseCalcSpecs()` 中定义，按导线分组的逐页分析在 `analyseTraverseCalc()`。

## 纸面与格子

| 项 | 值 |
| --- | --- |
| 纸面 | A4 横向；画布 1548 × 1130 设计单位 |
| 内容宽 | **277 mm**；按比例折出表高 **202.2 mm**，落在 210 mm 纸高内 |
| 行数 | 每页 11 行（固定，不动态；一条导线可以跨页） |
| 输入格 | 开始页 **47** = 11 行 × 4（点号 / 内角 / 导线长 / 高程）+ 首行 X / Y / 起算方位角；续页 **44**（首行没有这三个起算输入） |
| 计算格 | 开始页 **85** = 首行 5（改正后内角、Δx、Δy、改正后 Δx、改正后 Δy）+ 其余 10 行 × 8（再加方位角、X、Y）；续页 **88**（首行也把 X / Y / 方位角算出来） |
| 格子总数 | 每页 **155**（含 4 个表头格、19 个固定文字格） |
| 印刷矩形 | 每页 **151**（4 个表头格不画印刷格） |
| 三角热区 | 无；表G 没有斜分格，点击与输入直接落在矩形格上 |

开始页的首行是已知点：`s1-x` / `s1-y` / `s1-az` 三个输入格在纸面首行。续页的首行同样承接导线上一页的最后一点，但三格改为计算格，由上一页推算、不落盘；点号、内角、导线长、高程仍可编辑。第 2 行起的方位角、X、Y 在两种页上都是计算格，不可编辑。

## 数据模型

`state.pages.traverseCalc` 是页数组，每页形如：

```jsonc
{
  "meta":   { "date": "", "group": "", "calc": "", "check": "" },
  "role":   "start",            // "start" 开始页 / "cont" 续页
  "source": {
    "capturedAt": "", "sourceCount": 0, "overflow": 0, "heightCount": 0
  },
  "rows": [
    { "id": "", "ang": "", "len": "", "h": "", "x": "", "y": "", "az": "" }
    // 固定 11 行
  ]
}
```

- `meta` 四项对应纸面表头：`date` 日期、`group` 班·组、`calc` 计算人、`check` 复核人。新增页沿用当前页表头。
- `role` 决定这一页是导线的开始页还是续页。第 1 页永远是开始页；其余页只有显式写了 `"cont"` 才是续页。连续的续页属于它前面最近的开始页。旧项目、旧单表文件没有这个字段，全部按开始页载入，数据不动。
- `source` 记录**带入当时的本项目状态**，不记组员姓名，也不记项目 id：`capturedAt` 是带入时间（ISO 字符串）；`sourceCount` 是表一的已开始测站数；`overflow` 是带入时超出导线可用页容量的站数；`heightCount` 是从表六实际写入的高程个数（含首行起点高程）。这些字段只在提示与说明里用，不参与计算，且**只读开始页的记录**；续页上的 `source` 是空白，不参与计算。旧版「一页一个组员」的 `member` 载入时只迁这四个计数，姓名与项目字段丢弃。
- `rows` 固定 11 行，每行 `{ id, ang, len, h, x, y, az }`，空行也保留。`x` / `y` / `az` 只在开始页的首行是起算数据；续页首行的这三个存储值不参与计算（由上一页推算），切回开始页时会重新生效。
- 判断「一行有没有数据、导线走到第几行」只看点号、内角、导线长，开始页首行另加 X / Y / 方位角。**高程是纯记录**，只填高程的空行不会拉长导线；续页首行的休眠 X / Y / 方位角也不算行数据。`used`、`row-gap`、分页标签与带入后的已填行数都按这一条口径；「整条导线一行都没有」也按它判断。
- 行号是**全导线**的：第 *p* 页（0 基）第 *r* 行（0 基）对应导线第 `p×11 + r + 1` 行。上一页没写满时，空行也占位，所以续页总是从第 12、23… 行开始，不会自动接在上一页最后一个非空行之后。
- `settings.traverseCalc = { angleDir: "ccw", fBetaCoef: 40, kDen: 4000, connDir: "left", coords: {…}, coordsPrompt: "pending" }`：

| 键 | 默认 | 范围 | 含义 |
| --- | --- | --- | --- |
| `angleDir` | `"ccw"` | `"ccw"` / `"cw"` | `"ccw"` = 顺时针（内角在右）；`"cw"` = 逆时针（内角在左） |
| `fBetaCoef` | `40` | 1–1000 | 角度闭合差限值系数，单位 ″√n |
| `kDen` | `4000` | 100–1000000 | 全长相对闭合差分母，要求 K ≤ 1/`kDen` |
| `connDir` | `"left"` | `"left"` / `"right"` | 连接角方向：左角 / 右角 |
| `coords` | P 为 `35958.860 / 6010.070`，T 空 | 米 | P/T 起算坐标（P 是课程固定点，T 按队号/组号/学号生成） |
| `coordsPrompt` | `"pending"` | `"pending"` / `"filled"` / `"dismissed"` | 起算数据软提示状态 |

旧项目缺这些键时取默认值；非法值也会被夹回默认。快捷栏与抽屉「计算口径」都能切换顺/逆时针，改口径只重算，不改数据。

- 起算坐标的存放位置：本版起属于表G 的 `settings.traverseCalc.coords`。旧项目里的 `settings.trigSummary.coords`（更早还有 `settings.traverseSummary.coords`）在载入时迁移过来：新位置一旦存在即为权威；否则按「表六有 T → 表四有 T → 任意一处」的顺序取，P 缺省补课程固定值。`coordsPrompt` 同样按这条链迁移。

- 旧项目、旧 v1 文件没有 `pages.traverseCalc`：载入补一张空白页（11 行全空），严格导入同样接受。旧页没有 `role` 时按开始页载入，**不会**自动把相邻旧页合并成一条导线（旧页可能重复或属于不同尝试）；带 `source.overflow` 的旧页会在抽屉与检查面板提示「重新带入可自动分页」。每页超过 11 行的单表文件会被拒绝。
- 页数上限与其它多页表一致，为 100 页；一条导线必须连续，所以带入时按「本条导线可用的页数」与「全表剩余 100 页」两个上限一起算容量。

### 存储与单表

- 项目里每页保存 `meta`、`role`、`source` 与 11 行 `rows`；表G 不在每次渲染时从别的表重算，带入或手填的值就是本页数据。
- 单表信封 `kind:"table", table:"traverseCalc"` 带走全部页（含 `role`、来源快照与 11 行）以及 `settings.traverseCalc`（含 `connDir` / `coords` / `coordsPrompt`）。导入只替换表G 的页与该表设置，其他表不动。
- 表G 文件的 `rows` 是快照：导入后不会因为当前项目的表一变了而自动重算；需要新数据时在抽屉里重新带入。

## 计算口径

### 内角与角度闭合差

- 每行的角度是**内角**，用「度.分秒」打包值（`1°02′03″ → 1.0203`）。映射带入时按表四口径：表一水平角均值取 `360° − value`，再打包成四位小数。
- 输入校验：分、秒都必须小于 60，角度小于 360°；首行方位角允许 `360.0000` 并折叠成 `0.0000`。负值、非数字、`90.6000`、`90.0060` 都判无效。
- Σβ 保留超过 360° 的度数（例如 `1620.0000`），用于 `fβ = Σβ − (n−2)×180°`，以秒计。
- 允许值 `= fBetaCoef × √n` 秒，默认 `±40″√n`。`|fβ| ≤ 允许值` 判合格，**严格大于**才超限；恰好等于允许值不报超限。
- 角度改正按**原值**等分反号：`v = −fβ ÷ n`，不取整，也不把余数堆到首行；每个角的改正数相同，直接参加方位角与坐标计算。跨页时 n 按全导线算，不按页拆开。例如 fβ = +2″、n = 4：每个角 −0.5″，不是「首行 +1″、其余 −1″」。
- 改正后内角 = 观测角 + 改正数，落成 D.MMSS 四位小数；秒 ≥ 59.50″ 先进位到分，避免写出 `xx.xx60` 这种自己解析不了的数。
- 落格只到四位小数（整秒），但**只是显示**：方位角、坐标增量用未取整的改正后角度计算。老师表里改正数显示到 0.1″（如 −5.3″）而计算用原值，本表不印改正数列，口径与之一致。

### 方位角

- **开始页**首行的方位角是起算数据，手填，不参加角度改正。抽屉「起算数据」可以由 P/T 与表四 β1/β2/d 解算后填入，也可以把十进制度换算成度.分秒后写入首行。续页首行的方位角是计算格，由上一页推算，不能编辑。
- 顺时针（`angleDir: "ccw"`，内角在导线右侧）：`α_next = α_prev + 180° − β`。
- 逆时针（`angleDir: "cw"`，内角在导线左侧）：`α_next = α_prev + 180° + β`。
- 内部值 `cw` / `ccw` 是历史命名，与实际多边形方向相反；界面上以「顺时针 / 逆时针」为准，旧项目保存的值不迁移。
- 上式里的 β 是**改正后**的内角；沿全导线逐行推算（跨页不间断），规范到 `[0°, 360°)`，按 D.MMSS 四位落格。
- 开始页首行方位角没填：角度改正与 fβ 照算，但方位角、坐标增量、改正后增量、坐标全部留空，页面为 `partial`，焦点在开始页的 `s1-az`。填了但不是有效度.分秒：同样停链，提示用度.分秒（例如 `45.3000`）。

### 坐标增量与全长闭合差

- `Δx = D·cos α`、`Δy = D·sin α`；`D` 是该行导线长（米），结果换成 mm 后四舍五入（0.5 mm 远离 0，负零归零）。
- `fx = ΣΔx`、`fy = ΣΔy`、`f = √(fx² + fy²)`，单位 mm；`ΣD = Σ导线长`，单位 m。
- 全长相对闭合差 `K = (f / 1000) ÷ ΣD`，要求 `K ≤ 1 / kDen`（默认 1/4000）。`f = 0` 时 K 记作 0，判合格；`K` 恰好等于 1/4000 也判合格，**严格大于**才超限。
- 坐标改正按边长比例反号分配：`v_xi = −fx × D_i / ΣD`、`v_yi = −fy × D_i / ΣD`。逐条取整到 mm，余数全部加给**全导线最长边**（并列时给先出现的一行），保证 `Σv_x = −fx`、`Σv_y = −fy`；跨页时 ΣD 与最长边都按整条导线取。
- 改正后增量 = 坐标增量 + 改正数；坐标从开始页首行 X / Y 起逐行累加、跨页连续，每步用 mm 整数，落格时换算成米、保留 3 位小数。
- 开始页首行 X、Y 没填：坐标留空，角度、方位角、增量、闭合差照算；只缺一个时提示「要成对填写」并把焦点放到缺的那格 `s1-x` / `s1-y`。
- fx、fy、f、K 超限只给警告，不阻断改正数分配与坐标推算。

### 高程列

- 高程只记录，**不参与**任何闭合差、改正数或坐标推算；不是数字时只给一条 warning，不阻断导线计算。
- 可以手填，也可以在映射时勾选「高程列同时取表六」（默认勾选）由表六带入。带入规则见下一节。

### 停算与提示

| code | 级别 | 含义 |
| --- | --- | --- |
| `row-gap` | warning | 中间出现空行，后面的数据不参与计算（续页的空行也占位） |
| `source-overflow` | warning | 带入时源导线超过本条导线的可用页容量，闭合结果被抑制 |
| `id-missing-*` | warning | 该行缺点号（点号只作标注，不停算） |
| `ang-missing-*` | missing | 该行缺角度 |
| `len-missing-*` | missing | 该行缺导线长 |
| `ang-invalid-*` | invalid | 角度不是有效度.分秒 |
| `len-invalid-*` | invalid | 导线长不是大于 0 的米数 |
| `h-invalid-*` | warning | 高程不是数字（只记录，不影响闭合） |
| `too-few-rows` | warning | 有效行少于 3，不构成闭合导线 |
| `az-missing` / `az-invalid` | missing / invalid | 首行起算方位角未填 / 无效 |
| `xy-missing` / `xy-pair` | missing | 首行 X、Y 都没填 / 只填了一个 |
| `fbeta-over` | warning | 角度闭合差超限 |
| `k-over` | warning | 全长相对闭合差超限 |

逐行检查点号、角度、导线长；**点号缺失只给 warning**，角度改正、方位角与坐标照常计算；角度或导线长缺项/非法时整条链停在该行，`fβ`、方位角、增量、坐标都不输出（`state: "partial"`）。行数少于 3 时在角度闭合差之前就停（`too-few-rows`）。`row-gap`、`id-missing`、`fbeta-over`、`k-over`、`h-invalid` 是 warning；除「首行就空、`used = 0`」与 `source-overflow` 会返回 `partial` 外，这些 warning 不改变 `ok` / `partial` 的判定。空页返回 `state: "empty"`，不给提示。

引擎给每条 issue 记 `row`（导线全局行号，0 基）与 `pageIndex`（导线内页序号）；面板把它换算成实际页，提示文案在多页时写成「第 p 页第 r 行」，点一条能跳到对应页并聚焦对应格。整条导线的提示（fβ / K / 截断）只有一条，挂在开始页，不会每页重复。

## 数据来源：本项目表一 ＋ 表六

### 来源与一条导线跨页

- 抽屉「选项 → 数据来源」固定为**当前项目**：不再选项目库里的其他项目，也没有组员姓名字段。表一、表六就是当前项目的表一、表六。
- 一条导线 = 一张开始页 + 紧跟的若干续页。第 1 页永远是开始页；第 2 页起在抽屉里选「接续上一页 / 独立导线」。点「带入本项目表一＋表六」作用于**当前页所在的那条导线**：从开始页起重写，按站数自动分页；当前页是续页时也一样，只是操作落在它的开始页上。
- 表一没有已开始的测站时拒绝带入，提示「当前项目的表一还没有已开始的测站，无从带入」。
- 带入后，抽屉写明「来源：本项目 · 表一 N 站 · 本条导线 P 页 · 表六高程 M 个 · 时间 带入」；表一的站数后来变了会提示「表一现在 K 站（上次带入 N 站）」。

### 取数

按「表一的页顺序、页内站顺序」取**全部**已开始测站，导线第 *i* 行对应第 *i* 站；每 11 行切成一张纸，第 12 站起进续页：

| 表G 列 | 取值 |
| --- | --- |
| 点号 | 表一该站站名；没有点名时留空，只给警告，不影响计算 |
| 内角 | 表四口径的内角：表一水平角均值取 `360° − value`，按度.分秒打包 |
| 导线长 | 往返平距平均值：本站目标②与下一站目标①的平均；表四的「平距平均值」与表六同一条边的平距平均是同一个数 |
| 高程 | 可选，来自表六的最终高程，见下 |
| X / Y / 起算方位角 | 不映射：首行手填，或由「起算数据」解算后一键填入 |

带入时按显示精度写值：角度 `toFixed(4)`、导线长 `toFixed(3)`。源表有单盘或读数未全的「暂按值」时，会在带入后提示回表一核对；缺角度或平距的行会留空，带入后由检查面板按 `missing` 报出。

### 高程列

带入时勾选「高程列同时取表六」（默认勾选；只对本次带入生效，不写进设置）：

- 导线首行取表六第 1 页表头的**起点高程**；
- 导线第 *j* 行（*j* ≥ 2）取表六第 *j−1* 条边的**最终高程**；行号是整条导线的，跨页照走（第 12 站起在续页上，取表六第 11 条边的高程）；
- 闭合导线最后一条边回到首点，那份高程没有对应的表G 行，**不写入**；
- 非闭合路线没有回程边，最后一点的高程照常写到最后一个有效行；
- 表六自身页数不够时（每页 17 条边），超出部分没有高程可取，对应行留空；
- `heightCount` 记录整条导线实际写入的个数（含首行起点高程）。

表六没有可用的起点高程（第 1 页表头没填）时，高程列保持空白并提示。带入的高程是数值快照，之后表六再改也不会自动同步，需要重新带入。

### 页容量与截断

- 带入时先算本条导线还能用几页：`min(100 − 开始页序号, 100 − 本条导线以外的页数)`；容量 = 页数 × 11 行。`sourceCount` 记表一总站数。
- 站数不超过容量时全部带入，自动补续页，`overflow = 0`。
- 只有达到 100 页上限时才截断：`overflow` 记没带进来的站数。只要 `overflow > 0`，引擎在解析前就返回 `partial`，角度改正与闭合差全部抑制，并给一条 `source-overflow` 警告。
- 摘要卡按**带入时的快照**写「源导线 N 站 · 截断 / 上次只带入 M 行 / 未计算」，不拿当前页数反推容量——之后再手动加页也不会补上旧数据，要补就重新带入。
- 每页 11 行不动态扩展；要算更长的导线就让它跨页。

### 覆盖、清除与更新提示

- 本条导线已有数据时再次带入，先弹确认框，写明「第 N 页开始的导线已有数据（共 X 行，P 页）。带入会重写前 M 页；多余的 R 页续页会删除；表头不动。后面的页会顺延。」取消则整条导线保持原样。
- 「清除来源记录」只在开始页出现：清掉开始页的 `capturedAt` / `sourceCount` / `overflow` / `heightCount`，整条导线的行保留，可直接手改；表一、表六不受影响。
- 「清空本页」：
  - 开始页：清掉来源记录与 11 行，保留 4 项表头与开始页身份；后面若还有续页，确认框会说明这些续页将无法闭合。
  - 续页：只清本页 11 行，角色仍是续页；开始页、其它续页与表头都不动。
- 「删除本页」：
  - 删开始页且后面紧跟续页：确认框写明「后面的续页会成为新的开始页，首行 X / Y / 方位角需要重新填写」；删除后下一张续页提升为开始页，它的来源记录与首行 X / Y / 方位角会被清空——旧坐标与旧快照不随纸张搬。
  - 删续页：后面的续页前移一页（11 个站槽），角色不变。
  - 表一、表六都不受影响。
- 「接续 / 独立导线」切换：切成续页时首行三格改为计算格，本页原有的 X / Y / 方位角不删除但不再参与计算；切回开始页时它们重新生效，需要自己检查或解算。第 1 页不能切成续页。
- 新增页默认是**当前导线末尾的续页**（不是整份文档末尾）；要另起一条导线，在抽屉里切成「独立导线」。当前页没写满时加续页会产生空行，检查面板会按 `row-gap` 提示。
- 带入时的 `sourceCount` 与当前表一站数不一致时，抽屉提示「表一现在 K 站（上次带入 N 站），需要新数据时重新带入」；不再比较项目库其他项目的更新时间。
- 底栏分页标签写「第 X / Y 页 · 第 a–b 站」：a、b 是导线站号，按**连续参与计算**的行数算；整页还没有数据时写「第 a–a+10 站（空白）」；断行之后的页写「第 a 站起（未参与计算）」。页脚与打印仍是纸张页码「第 X 页」。

## 起算数据解算

每条导线只有**开始页的首行**是已知点。课程给的是 P、T 两个固定/生成点与连接角 β1、β2、连接边 d：解算一次就能得到开始页首行的 X / Y 与起算方位角，不必手算。

### P / T 坐标

- P 是课程固定点：N = 35958.860、E = 6010.070，默认已填，一般不用改。
- T 按组员的队号、组号、学号生成（见下）；生成后还可以补小数。
- P/T 四项存放在 `settings.traverseCalc.coords`，与页面数据分开；所有导线共用一套 P/T。

### T 生成器

- `N = 35600 + 队号×10 + 组号`、`E = 6200 + 学号后 2 位`。例：3 队 4 组 56 号 → T =（35634，6256）。
- 队号、组号从 1 起；学号后 2 位填 0–99。生成的是整数部分，小数可自己补。

### 连接角与连接边（表四表头）

- β1（在 P）、β2（在点 1）与连接边 d（P–1）直接填在**表四（表一汇总）的表头**，不在这里重复造输入。抽屉「起算数据」只读显示三格的当前值，并提供「打开表四表头」按钮。
- 三格任一未填或格式非法时，解算停在该步，预览逐条列出缺项；「计算并填入首行」不可用。

### 左角 / 右角

课程示意图把 β 画在导线左侧，默认按**左角**：

- 左角：`α_P1 = α_PT − β1`，`α_12 = α_P1 + 180° − β2`；
- 右角：`α_P1 = α_PT + β1`，`α_12 = α_P1 + 180° + β2`。

`α_PT = atan2(E_T − E_P, N_T − N_P)`，自北起顺时针。连接角方向与本表「计算口径」的顺/逆时针是两回事：后者管闭合导线的内角改正与方位角推进，前者只管从 P/T 解出首行。

### 解算结果与填入首行

- 预览给出：α_PT 与 P–T 距离；α_P1；`x1 = N_P + d·cos α_P1`、`y1 = E_P + d·sin α_P1`；α_12。角度全部按整数 0.01″ 运算，x1 / y1 取整到 mm、显示 3 位小数。
- 「计算并填入首行」只写本条导线**开始页首行**的三格：`x = x1`、`y = y1`、`az = α_12`（度.分秒打包）。点号、角度、导线长、高程都不动。当前页是续页时，快捷栏「起算数据」会先跳回开始页再打开抽屉；续页抽屉里没有起算输入，只有「打开开始页」。
- 开始页首行已有 X / Y / 方位角时先弹确认框；只有全解算成功（六项输出齐全）才允许写入。
- 开始页的首行（带入后就是表一的第 1 站）角度仍来自表一：它是第 1 站在闭合导线 1→2→…→n→1 中的内角（后视最后一站、前视第 2 站）。β2 是连接测量在 1 点处对 P 的另一条观测（P–1–2），与首行内角不是同一个角；β2 只参与解算 α_12，不写回首行角度，也不回写表四。

### 十进制度换算（手填备用）

不想用 P/T 解算、手上只有十进制度时，「方位角换算」小节可把 0–359.9999 的十进制度换成度.分秒，直接写入首行方位角。这一步不依赖 P/T。

## 屏幕摘要卡与检查面板

- 纸面右上角浮一张「计算摘要」卡，四行：

| 行 | 内容 |
| --- | --- |
| `n · ΣD` | 参与计算的行数、ΣD（3 位小数，m） |
| `fβ` | fβ 与允许值，例如 `+2.00″ / ±80.00″`；超限标红 |
| `fx fy f` | `+2 +0 2.0 mm` |
| `K` | 实际 `1/N` 与要求的 `1/4000`；超限标红 |

- 卡片按**整条导线**算：开始页与每一张续页都显示同一个 n / ΣD / fβ / fx fy f / K，不按页拆开。
- 空页显示「待填」与 `—`；`partial`（缺项、截断等）时卡片用虚线边框，仍显示已算出的部分；`fβ` 或 `K` 超限时整卡边框转红。旧版截断数据卡写「源导线 N 站 · 截断 / 上次只带入 M 行 / 未计算」，是带入时的快照。
- 点摘要卡打开检查面板的「填写检查」。检查面板按页汇总所有 issue（缺项、无效值、断行、截断、超限），同页内按导线行号排序，点一条会跳到对应页并把焦点放到问题格（如 `s2-ang`）；整条导线的提示只出现一次，挂在开始页。
- 摘要卡只在屏幕出现：舞台窄于 1000 px 时整块收起，打印时完全不生成。它只是显示层，不参与任何计算。

## 打印

- A4 横向，内容宽 **277 mm**，表高 **202.2 mm**，留出上下余量；打印样式由 `PAPER.traverseCalc` 与 `@page { size: A4 landscape; margin: 0 }` 决定。
- 屏幕与打印的页脚都写「第 X 页」，跟着当前页 / 打印的第 X 页走，不是固定「第 1 页」。
- 多页时可选「打印本页」或「打印全部页」，全部页逐页输出；一条跨页导线打印出来就是连续的多张纸，续页首行的 X / Y / 方位角是计算值，照常印出，不是空白。
- 没有真实值的计算格不打印（`realOnly`）；输入格为空也不打印，空白表不会印出「待填」。
- 计算值按纸面精度落格：坐标与增量换算成米、保留 3 位小数；角度与方位角用度.分秒四位。
- 「计算摘要」卡不打印。

## G3 边界

以下内容本版**未做**，界面上也不会出现对应按钮或假入口：

- 组长参考点自检（课程 PPT 的「组员 1 点与组长相差 0~12 m、1–2 方位角相差 15° 以内」）；
- 从表二取数；
- 每页 11 行动态扩展（跨页是正路，纸内不加行）；
- 自动合并旧版的多张表G 页（旧页可能重复或属于不同尝试，只提示重新带入）；
- 把摘要卡印到纸上。

表六不再持有 P/T 起算坐标：那一块已整体搬到表G 的选项里，表六只有平差口径与备注。
