# 右侧导航轨

> 2026-11-04 · AI 助手 · 按可露希尔终端同款重做，只改前端显示层

## 需求

- 把 M2 的右分支轨（每轮一个圆点、整体占流内宽度）换成可露希尔终端同款的导航轨：**每轮一根横条**，光标邻近的条按距离伸长、加深；当前可见轮为主题蓝；点击驻场为琥珀色并跳转到该轮。
- 兼顾对话树：悬停 / 驻场浮窗里显示该轮用户消息与回复预览；有兄弟分支的轮在条右侧带蓝点，≥3 个时再显示数量；浮窗列出全部兄弟的用户消息，点击直接切换分支。
- 只取交互语义，不搬可露希尔代码与素材；不改 Rust / `tauri.conf.json` / `agent.json` 版本 / 项目库 schema。

## 位置模型

- 轨道是 `.agent-shell` 内的绝对定位元素：`right: 12px; top: 0; bottom: 0; width: 52px`，`display:flex; flex-direction:column; justify-content:center`，纵向在**助手区**（标题栏 / 顶栏以下）居中，而不是在视口居中。
- 不用 `position: fixed` + `transform` 居中：`transform` 会给 `position: fixed` 的浮窗另建包含块，浮窗就不能按视口定位；改用 shell 的 `position: relative` + 绝对轨道，横条不动、浮窗仍是视口固定。
- **主列宽度不变**：旧轨道（28px）原本占流内宽度，加上 12px 间距与 10px 内边距共 50px；轨道脱离文档流后，`.agent-shell` 右侧改留 `padding-right: 50px`，聊天主列右缘与改动前逐像素一致。≤1180px 轨道隐藏时，`padding-right` 回到 10px。
- 轨道宿主 `pointer-events: none`，每行 `pointer-events: auto`；行内有一枚覆盖整行（含分支位）的透明按钮承担悬停、点击与键盘聚焦，横条与分支标记本身不接收指针。轨道空白处不挡聊天区的点击。

## 横条

| 属性 | 值 |
|---|---|
| 行高 | 桌面 8px；触屏（`hover: none`）14px |
| 条的静止宽 / 高 | 10px / 3px，圆角胶囊 |
| 邻近伸长 | 宽 = `10 + grow × 14`，最宽 24px |
| 邻近系数 | 距离 0 → 1，1 → 0.72，2 → 0.45，3 → 0.2，更远 → 0 |
| 静止透明度 | `rgba(--agent-rail-rgb, 0.16)`；grow 每 1 加 0.3，最高 0.46 |
| 当前可见轮 | 主题蓝 `--agent-accent`（亮色 `#2563eb`） |
| 点击驻场轮 | 琥珀 `--agent-rail-pin`；亮色 `#f59e0b`，暗色 `#e0b166` |

- 只有渲染出来的轮才有横条：`nodes.slice(-contextSize)`，再截最近 `RAIL.CAP = 32` 轮。更旧的轮次没有 DOM，跳不过去，所以不画。
- 悬停行用 `requestAnimationFrame` 合并重绘；移出整个轨道宿主时清空悬停。条宽与颜色有 0.15 秒过渡；`prefers-reduced-motion: reduce` 下取消过渡。
- 触屏没有悬停：行高加到 14px，命中区上下各再扩 3px（`inset: -3px 0`），点击直接驻场并跳转。

## 当前可见轮

- 每帧（滚动、resize、流式输出后）量出每个 `.agent-row[data-nid]` 的矩形，取助手行；与消息区视口**严格相交**（`bottom > viewTop && top < viewBottom`）的轮标 `.is-visible`，横条转主题蓝。
- 用户行与助手行共用 nid，只取助手行分组，避免一条轮被算两次。
- 可见判定是纯函数 `RAIL.visibleNids(rows, viewTop, viewBottom)`，Node 直接测试。

## 浮窗

- 悬停或驻场时在轨道**左侧**弹出 256px 白卡（`.agent-rail-tip-card`，外层 268px 含 12px 透明过桥），`position: fixed`、`z-index: 21`；按行矩形垂直居中，上下各留 8px 夹在视口内，左缘 = 行左缘 − 浮窗宽。
- 内容自上而下：
  1. 该轮用户消息（单行省略）；
  2. 有兄弟分支时：全部兄弟的用户消息按钮，当前分支高亮，点击切换；
  3. 分隔线下的助手回复预览，最多 3 行（`-webkit-line-clamp: 3`），尚未回复时显示「（尚未回复）」。
- 浮窗是行元素的 DOM 子节点，虽然视觉上在轨道左侧；行 `mouseleave` 时用 `row.contains(event.relatedTarget)` 判断，移进浮窗不算离开，否则浮窗会立刻消失。
- 流式生成时消息文本直接更新而不重建轨道，`syncRailTips` 会同步刷新已打开浮窗的预览文本。
- 同一时刻只开一个浮窗。点击浮窗里的兄弟按钮切换分支后，浮窗关闭并把焦点还给对应的横条按钮。

## 点击、驻场与跳转

- 点击横条：平滑滚动到该轮，轮顶停在消息区顶下方 8px（`RAIL.jumpTop`），同时把该轮设为**驻场**（琥珀），浮窗保持打开；再次点击同一条取消驻场，浮窗关闭。
- 驻场不因鼠标移开而消失；`Esc` 先关驻场（不关设置弹窗等其他层）；切换会话、切换项目、切换模式、发送新消息都会清空驻场与悬停。
- 跳转时 `followBottom = false`，不跟流式输出抢滚动；用户再滚到底部或点「回到底部」恢复跟随。
- 点击切换分支沿用 M2 的 `selectBranch`：更新 `path`、保留滚动位置记忆、把目标轮滚到视口中央；来源是导航轨时把焦点还给对应横条。
- 分支标记：兄弟 ≥2 显示 6px 蓝点，≥3 在点右侧再显示数量；分支位固定 24px，横条宽度变化不影响标记位置。

## 窄窗与主题

- `≤1180px`：整个 `.agent-branches` 隐藏，`.agent-shell` 的右侧预留回到 10px；切换分支改用用户气泡上方的 `‹ 2 / 3 ›` 按钮。
- 亮色令牌 `--agent-rail-rgb: 17, 24, 39`、`--agent-rail-pin: #f59e0b`；暗色 `--agent-rail-rgb: 231, 227, 217`、`--agent-rail-pin: #e0b166`。暗色浮窗卡用 `--agent-bg` 与独立阴影。
- 旧的圆点轨、分支徽标与 `#agent-branch-pop` 浮层已全部移除；消息级切换器保留。

## 明确不做

- 轨道不参与聊天列宽拖拽，也不改变 420px 最窄列。
- 不做分支删除、合并、命名、树状总览；不做滚动位置缩略图或全文导航。
- 不为超出 32 轮的旧轮虚拟化 DOM；不把轨道状态写入 `store.json` / `agent.json` / 备份。
- 不在窄窗给轨道换成抽屉或浮动按钮；窄窗直接用消息内切换器。
