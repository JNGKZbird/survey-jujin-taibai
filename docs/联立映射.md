# 表一 → 表三 · 联立映射

联立是项目级开关，默认关闭。关闭时表一与表三互不影响；打开后出现独立的「联立映射」模块，表一按映射表把数据写入表三。

## 开关

- 入口：表一、表三的快捷选项里都有「联立 开 / 联立 关」；也可以从联立映射页右上角「解除联立」关闭。
- 开启需要确认；如果表三已有数据，确认框会明确提示同格内容将被覆盖。
- 开启前自动备份当前项目的七张表；备份原因记为「开启联立前」。表四/表五/表六/表G 不参与联立，但会随快照一起备份与恢复。
- 映射模块只在开关打开时存在：关闭后标签页与映射表一起隐藏。
- 关闭（解除联立）需要确认。已写入表三的数值保留并恢复可编辑；映射与备份保留，下次开启继续使用；「上次写入位置」记录清空，因此重新开启后不会删除解除期间编辑过的表三值。

## 映射表

每个表一测站占一行，显示来源站名、两个目标、将写入表三的四行、目标位置与配对状态。

- **自动位置**：全局站号 `g = 4 × 表一页序号 + 站内序号`（都从 0 起）；表三页 = `⌊g / 6⌋ + 1`，站 = `g mod 6 + 1`。表三页数按 `max(1, ⌈4 × 表一页数 / 6⌉)` 估算，有手工目标时取更靠后的页。
- **手工位置**：逐站选择表三页与站。目标页超出当前允许页数时，该站退回自动位置；映射表会标成自动。
- **目标配对**：`①→1 ②→2` 是默认配对，`互换` 后变为 `②→1 ①→2`。交换只换两个目标，盘左/盘右绝不反转。
- **恢复自动映射**：清除全部手工位置与目标交换，按全局站号重排；执行前备份（「恢复自动映射前」）。
- **重新同步**：立即按当前映射把表一重新写入表三；表一本来就有约 180 ms 防抖写入。
- **恢复备份**：见下文「备份与恢复」。
- 映射存为项目元数据 `linkage.mapping`：`stations` 记录手工位置与交换，`last` 记录每个表一站上一次实际写到的表三格。两者都不进入七表的 `state`。

映射与表三页面的关系：表三页按需自动新建，已有页不删；手工把两个站放到同一格会形成冲突，不会二选一。

## 写入规则

| 表一行 | 内容 | 表三行 |
| --- | --- | --- |
| r1 | 目标① 盘左 | 1（L①） |
| r3 | 目标② 盘左 | 2（L②） |
| r2 | 目标① 盘右 | 3（R①） |
| r4 | 目标② 盘右 | 4（R②） |

- **读数**：只抄水平度盘原始 `{d, m, s}`，不换算、不归一化 360；未填全的读数原样抄入并给软提示。
- **竖盘**：任何情况下都不进入表三，负竖直角也不抄。
- **斜距**：抄对应盘面的斜距原值（盘左行抄盘左斜距，盘右行抄盘右斜距），不是平均值，也不是平距。两盘斜距相对较差超过 1/10000 时只给软提示，不改写数值。
- **站名**：写入表三站号，超过 8 个字截断；表一未填站名时表三留空。
- **目标名**：超过 20 个字截断；两个目标按行序配对，交换只调整目标顺序。
- **表三表头**：只填 `date`、`observer`、`recorder`、`group` 四个字段，且只填空值，绝不覆盖已有内容。每个表三页取第一个向它供数的表一页；日期由表一页的 `year/month/day` 归一化为 `YYYY-MM-DD`。天气、仪器、草图、距离相对误差列不写。
- **计算格**：半测回角值、半测回差、一测回角值始终由表三自身计算，联立不写入。

### 示例

两页表一、每页 4 个测站：

- 表一第 1 页 → g=0..3 → 表三第 1 页第 1~4 站。
- 表一第 2 页 → g=4..7 → 表三第 1 页第 5~6 站，表三第 2 页第 1~2 站。
- 表三共 `⌈4 × 2 / 6⌉ = 2` 页。

## 同步与冲突

- 在表一输入后约 180 ms 防抖同步；切换模块、切页、删除页面等操作前会先冲刷待写入。
- 两个及以上「有数据」的表一站指向同一个表三格：所有相关站暂停写入，保留表三原有内容，映射表状态标为「冲突停写」，并在提示区数出冲突数。改动任一站的表三位置或目标配对即可解开。
- 空白表一站不占用目标格。它只会清理自己 `last` 记录过的表三格：先清空表一，再改位置时，旧格若没有别的站占用则一并清理。
- 删除表一页（联立中）：先备份，清掉该页各站上次写入的表三数据，后面的表一页键位前移并重新同步。
- 清空表一页（联立中）：先备份，随后同步按空白站清理对应表三格。
- 联立中不能手动新增或删除表三页，也不能清空表三页；表三页数由表一与映射决定。
- 导入（联立中）：先备份并清空 `last`，再按现有映射同步。只写表一有数据的测站，不会用空白站清理导入表三里的其他内容。
- 单表导入（联立中）：表一、表三的单表文件直接拒绝，不弹确认框，数据不变；表二不参与联立，可以正常单表导入。要单独恢复表一或表三，先解除联立，导入后再重新开启。

## 备份与恢复

备份形如 `linkage.backup = { at, reason, state }`，`state` 是操作前的完整七表快照。只保留最近一份，新的操作会覆盖旧的。

| reason | 触发时机 |
| --- | --- |
| `enable` | 开启联立前 |
| `traverse-delete` | 联立中删除表一页前 |
| `traverse-clear` | 联立中清空表一页前 |
| `import` | 联立中导入前 |
| `auto` | 恢复自动映射前 |

「恢复备份」先确认，再恢复整份七表快照：

- 备份原因是 `enable`：恢复后联立保持**关闭**，并回到表三。
- 其他原因：联立保持**开启**，清空 `last` 后按当前映射重新同步，因此恢复的表三值可能立即被表一覆盖——这是把表一恢复成备份时的样子后的必然结果。

## 只读界面

联立期间表三的数据格全部只读，表头仍可编辑，计算格照常显示。自动填入的格有极淡的冷色底；触屏点进只读格或尝试键入时，会提示「联立中：本格由表一自动填入，解除联立后可编辑」。解除联立后冷色底与只读一起消失。
