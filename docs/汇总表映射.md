# 表四 / 表五 / 表六 / 表G：汇总与映射

表四「导线测量原始数据汇总」与表五「支水准测量原始数据汇总」不是独立录入的数据表，而是来源表的只读投影：

- 表四全部正文由**表一**推导，表头 9 项可编辑；固定一页，不能增删页。
- 表五全部正文由**表二**推导，每页只有 8 个姓名与 3 项表头可编辑；人数超过 8 人时像表一一样新增页，第 2 页接第 9–16 人。
- 表六同属强制映射，每页 17 条边，测点更多时可新增页；公式与打印宽度见 `docs/三角高程平差.md`。较差允许值有三档预设，在抽屉「平差口径」用分段控件切换：`60√D`（`K·√D`，`D` 以 km 计，`K` 默认 60）、`40√D`（此前用过的口径）与 `0.4×S`（`K×S`，`S` 为平距、以 m 计，`K` 默认 0.4；等价于教材的 `0.4S` m、`S` 以 km 计）；系数也可直接改。闭合差允许值仍是 `40√ΣD`；表四的 `dh-mis` 误差色允许值跟随表六当前公式。
- 表G 是当前项目表一与表六的**联合带入**，带入后的行会落在页面里、可手改，不是每次渲染重投影；**一条导线可以跨页**，第 1 页是开始页、第 2 页起是续页。详见本文「表G 的联合映射」与 `docs/导线计算表.md`。
- 表四、表五、表六的正文都不能清空，也不写进项目状态，每次渲染时从来源表重算；表G 的行则写在项目状态里。

对应纯计算模块是 `web/assets/calc-summary.js`，不碰 DOM。表格尺寸、打印方向与 meta 字段在 `web/assets/app.js` 的 `TABLES` 中定义。

## 表四：表一 → 表四

### 行与返测

按「表一的页顺序、页内站顺序」收集所有已开始录入的测站（启动判据与表一自己的 `stationStarted` 一致）。第 *i* 行对应第 *i* 个测站：

| 列 | 取值 |
| --- | --- |
| 点号 | 表一测站名 |
| 内角 | `360° − 表一本站平均水平角`，按「度.分秒」打包 |
| 平距往测 | 本站**目标②**的水平距离 |
| 平距返测 | **下一站目标①**的水平距离 |
| 平距绝对误差 | `|往 − 返| × 1000`，单位 mm |
| 平距平均值 | `(往 + 返) / 2`，单位 m |
| 高差往测 | 本站目标②的高差 |
| 高差返测 | 下一站目标①的高差 |
| 高差闭合差 | `(往 + 返) × 1000`，单位 mm |
| 高差平均值 | `(往 − 返) / 2`，单位 m |
| Σ | 各列「平均值」之和；内角按六十进制累加 |

「下一站」的取法：

- 测站数不超过 17：最后一站的下一站接回第 1 站（闭合导线）。
- 测站数超过 17：第 17 行仍取真实第 18 站，不绕回第 1 站；多出的测站不进入表四，状态提示「超限」并说明超出数量。

计算前先把平距与高差保留 3 位小数，再求误差/闭合差/平均值，避免浮点尾数把 mm 列算成 `10000.00000001`。高差公式与表一相同：`斜距 × sin(竖直角) + 仪器高 − 棱镜高`。

「Σ」合计按**纸面显示值**逐行相加：每个平均值先保留 3 位小数，再求和。平距与高差不先加原始值再取整——那样在 `.0005` 边界上，纸面「把这一列加一遍」会和 Σ 格差 1 mm。角度合计同样从每行显示的 4 位小数做六十进制累加。

### 角度合计

「度.分秒」打包值是 `1°02′03″ → 1.0203`，不能当十进制小数直接相加：

1. 每个内角先按 4 位小数写死；
2. 拆成度、分、厘秒；
3. 秒满 60 进分、分满 60 进度；
4. 再写回 4 位小数。

`packedParts` 会把秒先四舍五入到 2 位小数，否则 `3.0507` 会拆出 `6.999999999999673`，六十进制累加少一秒。

### 表头

`年份 / 基地 / 控制点 / 批次 / 队组 / 组长 / 连接角 β1 / 连接角 β2 / 连接边 d(P−1)` 共 9 项可编辑，随项目保存。连接角与连接边只是表头记录，不参与正文推导。

### 空值与部分值

- 只有一站时没有「下一站」，返测列留空，平均值/误差不编造。
- 目标只有单盘读数、或仪器高/棱镜高未填时，表一本身会给出「暂按现有值计算」；表四照常显示该值，并在计算格下方带注。
- 正文格 `realOnly`：没有来源值就留空，不显示「待填」。

## 表五：表二 → 表五

### 人员与分段

表五每页 8 行、8 个人，每人 4 段：

| 段序 | 内容 |
| --- | --- |
| 1 | BM1–BM0 往测 |
| 2 | BM1–BM0 返测 |
| 3 | BM0–1号点 往测 |
| 4 | BM0–1号点 返测 |

**一张表二页 = 8 个测站**：第 1 站的「测站编号」在跨 8 行的竖格里，其余 7 站各占一格。每人 7 组信息正好占一页；若某人的测站在一页里跨了两段，把后一段另起一页单独标归属即可。新增表二页沿用**当前页**的归属。

一段可以只对应一页，也可以对应多页；两种归属方式二选一：

#### 逐页归属（推荐）

表二每页在底栏有一个「归属」胶囊，点开标成 **第 N 人 · 某一段**：

- 表五对每人每段，把所有标到它的表二页合计；**页序不限**，可以跳着标，同一人同一段可以有多页；
- 没标归属的表二页不参与汇总；表五抽屉和检查面板会提示「未归属的页」；
- 人员序号范围 1–800（= 表五 100 页 × 每页 8 人），超出的标签会被忽略并提示；
- 归属只是屏幕上的元数据，**不打印**在表二纸上，也不改变表二的任何计算；
- 首次开启时，软件按下面的「按页块」规则给现有页补齐归属，**结果不变**，之后可以逐页改。

#### 按页块（旧规则）

选项抽屉「分段」里的「每段页数」`legPages`（默认 1，范围 1–20）表示**每一段占几张表二页**。设表五当前是第 *p* 页（从 0 开始），共有 *P* 页：

- 每人页数 `perPerson = 4 × legPages`
- 每页 8 人需要 `pagePages = 8 × perPerson` 页表二
- 第 *p* 页第 *r* 行（从 0 开始）是全局第 `p × 8 + r + 1` 人，使用表二第 `(p × 8 + r) × perPerson` 到 `(p × 8 + r) × perPerson + perPerson − 1` 页（从 0 开始计数）
- 全部表五页最多计入表二前 `P × 8 × perPerson` 页；超过的页给一条「未计入」提示
- 段顺序固定为「往、返、往、返」，每段把该段所有页、所有已开始测站的高差中数相加

`legPages = 1` 时，表五第 1 页第 1 人用表二第 1–4 页，第 2 人用第 5–8 页，依此类推；表五第 2 页第 1 行（全局第 9 人）从表二第 33 页开始。

#### 切换与持久化

- 表二底栏胶囊 →「改为逐页归属」；表五抽屉 →「改为逐页归属」/「改回按页块分配」。
- 设置 `levelingSummary.ownerMode` 是三态：`true` 逐页归属、`"blocks"` 强制按页块、`false` 自动（有归属标签就按标签，否则按页块）。强制按页块时归属标签保留但不生效，刷新后仍然有效。
- 删除表二页会让后面的人员序号不变（归属跟着页走），但页块模式下的页序会整体前移，删除前会提示。

### 段内计算

对一段内的所有页、所有已开始测站，取水准计算模块的高差中数（mm），求和后除以 1000 得米：

| 列 | 取值 |
| --- | --- |
| 往测 | 该段往测页的高差中数之和，m |
| 返测 | 该段返测页的高差中数之和，m |
| 闭合差 | `(往 + 返) × 1000`，mm |
| 平均值 | `(往 − 返) / 2`，m |

BM1–BM0 与 BM0–1号点各自一组「往 / 返 / 闭合差 / 平均值」。

### 表底

- **平均值**：本页 8 人该段平均值的算术平均（只统计已算出的行），m。
- **中误差**：本页 8 人该段平均值的**样本标准差**（除以 `n − 1`），再乘 1000，单位 mm；不足 2 人时留空。
- 缺页：本页对应的表二页段不足 `pagePages` 时，缺页的段先按已有测站合计，状态提示「超限」，抽屉写明这一段还缺几页。
- 多页：表二页数超过全部表五页的容量 `P × pagePages` 时，最后的表五页给一条信息提示；新增表五页后，多出的页会归入新页。
- 段内有测站未算完（缺读数）时，该段按已算出的测站合计，并带注「本段有测站未算完」。

### 表头与姓名

每页 8 个姓名与「组长 / 副组长 / 日期」可编辑，随项目保存。新增页沿用当前页表头，姓名保持空白；正文由表二推导，不能直接改。

### 增删页

- 底栏「＋新页」在表五末尾追加一页，对应下一组 8 人。新增后自动跳到新页。
- 「删除本页」只删除该页的 8 个姓名与人员映射，表二原始数据不动；后面的表五页会前移，对应人员段落随之重排。
- 「清空姓名」只清当前页的 8 个姓名，表头保留。
- 表五页数上限与表一相同，为 100 页。

## 表G 的联合映射

表G「导线计算表」的行不是自动投影，而是从**本项目的表一＋表六**带进来的一次性快照：带入后落在页面里，可以继续手改；重新带入会覆盖整条导线（先确认）。**一条导线可以跨多页**——每页仍固定 11 行，第 1 页是开始页（放起算数据），第 2 页起是续页，承接第 12、23… 站；角度闭合差、改正数、方位角与坐标按整条导线统一计算一次。表一是数据根基。开始页首行的 X / Y / 起算方位角可由 P/T 起算坐标与表四表头的 β1 / β2 / d 解算后一键填入（见 `docs/导线计算表.md`「起算数据解算」）。

### 来源与一条导线跨页

- 抽屉「数据来源」固定为**当前项目**，不再选项目库里的其他项目，也没有组员姓名。也可以完全手填。
- 连续的续页属于它前面最近的开始页，合起来是一条导线；一条导线可以有多页。要同时算另一条导线，在该导线末尾新增页并把角色切成「独立导线」（成为新的开始页），或在它后面另起一页，两条导线互不影响。
- 带入按表一已开始测站数自动分页：站数多则自动补续页，站数变少则删除多余续页（删除前确认）；只有超出 100 页上限才截断。
- 表一没有已开始的测站时拒绝带入。
- 带入后开始页抽屉写明「来源：本项目 · 表一 N 站 · 表六高程 M 个 · 时间 带入」与本条导线页数；续页抽屉只显示「本页是第 N 页开始的导线的续页（第 a–b 站）」与「打开开始页」，来源记录与起算数据都在开始页。表一站数后来变了会提示重新带入。

### 取数

按「表一的页顺序、页内站顺序」取全部已开始测站，导线全局第 *i* 行对应第 *i* 站；每 11 行切一页，第 *p* 页第 *r* 行即全局第 `p×11 + r + 1` 行（从 1 数）。

| 表G 列 | 取值 |
| --- | --- |
| 点号 | 表一该站站名 |
| 内角 | 表四口径的内角：表一水平角均值取 `360° − value`，按度.分秒打包 |
| 导线长 | 往返平距平均值（本站目标②与下一站目标①的平均）；表四的「平距平均值」与表六同一条边的平距平均是同一个数 |
| 高程 | 可选，来自表六的最终高程，见下 |
| X / Y / 起算方位角 | 不映射：首行手填，或由「起算数据」解算后一键填入 |

带入时角度按 `toFixed(4)`、导线长按 `toFixed(3)` 写值。源表有单盘或读数未全的「暂按值」时，带入后提示回表一核对；缺角度或平距的行留空。

### 高程列

勾选「高程列同时取表六」（默认勾选；只对本次带入生效）：

- 首行取表六第 1 页表头的**起点高程**；
- 第 *j* 行（*j* ≥ 2，按导线全局行）取表六第 *j−1* 条边的**最终高程**，跨页照走；
- 闭合导线最后一条边回到首点，那份高程没有对应的表G 行，**不写入**；非闭合路线最后一点的高程照常写到最后一个有效行；
- 表六没有可用的起点高程时，高程列保持空白并提示。

带入的是数值快照，之后表六再改不会自动同步。

### 页容量与截断

一条导线可用页数受两个上限约束：整份文档最多 100 页（`MAX_PAGES`），且新补的续页不能把后面的页挤出 100 页。带入时容量 = 可用页数 × 11 行；站数超过容量才会截断，`sourceCount` 记总站数、`overflow` 记超出数，闭合差被抑制并警告「源导线有 N 站，本表 P 页共 C 行；只带入了前 used 行」。恰好填满时全部参与。正常实习规模（数十站）远低于上限，实际不会触发。

截断是**带入当时的快照**：之后再手动加页也不会补上旧数据，摘要卡与抽屉只说「上次只带入多少行」，重新带入才会按当前页容量补足。

### 覆盖、清除与更新提示

- 本条导线已有数据时再次带入，先确认「第 N 页开始的导线已有数据（共 X 行，P 页）。带入会重写前 M 页；多余的 R 页续页会删除；表头不动」；取消不覆盖。带入始终作用于该导线的开始页，在续页点带入也一样。
- 「清除来源记录」只清开始页的 `capturedAt` / `sourceCount` / `overflow` / `heightCount`，整条导线的行保留，可直接手改。
- 「清空本页」只清当前页的行与表头以外的内容：在续页上只清本页 11 行，开始页与其它续页不动；在开始页上会一并清掉来源记录与起算 X / Y / 方位角（先确认，后面的续页将无法闭合）。「删除本页」删开始页时，紧随的续页提升为新的开始页（首行起算数据需重填）；删续页时后面的续页整体前移 11 站。两者都不动表一、表六。
- 带入时的 `sourceCount` 与当前表一站数不一致时，抽屉提示「表一现在 K 站（上次带入 N 站），需要新数据时重新带入」。
- 分页标签写「第 2 / 3 页 · 第 12–22 站」：前半是本导线内的页码，后半是该页承载的全局站号；本页还没有数据时写「第 12–22 站（空白）」，整页在已填数据之后时写「第 12 站起（未参与计算）」。新页默认接在当前导线末尾（角色为续页），按钮提示「接续第 M 页开始的导线，第 a–b 站；表头沿用本页」。

### 纸面与打印

表G 每页固定 11 行，不随来源项目的站数增减；站数更多时由续页承载，跨页的导线按连续纸张打印，续页首行的 X / Y / 方位角照常印出（计算值，不是输入格）。A4 横向、内容宽 277 mm，画布 1548×1130，折合表高 202.2 mm；多页时可「打印本页」或「打印全部页」，页脚逐页写「第 X 页」。屏幕上的「计算摘要」卡不打印。详细口径见 `docs/导线计算表.md`。

## 界面行为

- 顶栏的汇总/计算标签有「表四 导线汇总」「表五 水准汇总」「表六 高程」「表G 计算」，都在同一个舞台里渲染。
- 表四底栏固定显示「唯一页 · 自动汇总」，上一页/下一页/新页/删除本页全部禁用。
- 表五底栏是普通分页器，标签写明「第 2 / 2 页 · 第 9–16 人」；上一页/下一页、新页、删除本页都可用。
- 表六底栏同样是普通分页器，标签写明「第 2 / 2 页 · 第 18–34 条边」；新页追加 17 条边容量，删除本页只影响纸张分配，第 1 页的起点高程会迁移到新的第 1 页。
- 表G 底栏也是普通分页器，标签写「第 2 / 3 页 · 第 12–22 站」；新页接在当前导线末尾、默认是续页（要另起一条导线，在抽屉里把它切成「独立导线」），删除本页按角色处理（删开始页会提升下一张续页，见上），表一、表六不动。
- 状态胶囊：表四/表五/表六正常显示「✓ 已推导」，表G 显示「✓ 已完整」；有缺项、超限或截断时显示计数，点开「填写检查」可看具体原因。
- 表四的「清空本页」禁用；表五的「清空本页」变为「清空姓名」，只清当前页的 8 个姓名，保留表头；表G 的「清空本页」按页角色处理：续页只清本页 11 行，开始页清来源记录、起算数据与本页行（见上）。
- 选项抽屉不显示联立开关（汇总表与表G 不参与表一→表三联立），显示来源页数、已开始测站数、缺页/多页等只读信息。
- 字体大小：表四/表五/表六/表G 的 100% 基准就是设计尺寸，不再额外放大；屏幕缩放与打印互不影响。
- 表六（三角高程平差）同属强制映射汇总，但公式、限差与打印宽度不同，见 `docs/三角高程平差.md`；表G 是联合带入且正文可手改，见 `docs/导线计算表.md`。

## 打印

- 表四/表五/表G 都按 **A4 横向**输出，内容宽度 277 mm，保持设计稿比例（表G 折合表高 202.2 mm）；表六也是 A4 横向，但内容宽 226 mm（见 `docs/三角高程平差.md`）。

## 存储与兼容

- 表四页只保存 `meta`（9 项表头）；表五每页只保存 `meta`（3 项）与 `names`（8 个姓名）；表G 每页保存 `meta`、`role`（`start` / `cont`）、`source` 与 11 行 `rows`，其中 `source` 只在开始页有值，续页是空记录。表四/表五/表六的正文是计算覆盖层，不占项目数据；表G 的行是本页数据，会落盘。
- 项目状态仍是 v1 信封，页键增加 `traverseSummary`、`levelingSummary`、`trigSummary`、`traverseCalc`；表四只允许 1 页，表五/表六/表G 允许多页（上限 100）。旧 v1 文件缺少这些键时，载入会各补一张空白页（表G 也补一张空白导线页）。
- 旧 `正式版` 不识别汇总页与表G，会忽略这些键；用「导出整个项目（七表）」给旧版时，旧版仍能读三张记录表。
- 单表信封也支持 `table: "traverseSummary" | "levelingSummary" | "trigSummary" | "traverseCalc"`：表五文件会带走全部页；表六文件会带走全部页的表头与备注，以及该表设置（路线档、较差公式与两个系数、闭合差系数）；表G 文件会带走全部页的 `meta` / `role` / `source` / 11 行与 `settings.traverseCalc`（含起算坐标、连接角方向与提示状态），跨页导线的页序与角色原样往返；旧文件没有 `role` 时全部按开始页载入，不会自动合并。导入只替换该表的页与该表设置，来源表不动；导出的单表文件里，其余六表各是一张空白页。
- 联立开关、映射与备份不涉及汇总表与表G；汇总表跟随来源表内容自动变化，表G 要重新带入才更新（重新带入也会按当前站数自动增删续页）。
