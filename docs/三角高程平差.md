# 表六：三角高程测量平差

表六「三角高程测量平差表」是**表一**的第二个强制映射表，和表四同源：正文不接受手填，每次渲染都从表一重算。

- 可编辑的只有表头 `起点高程（米） / 计算 / 检核 / 班·组`，以及整列合一的备注。
- 每页 17 个数据行；测点更多时用底栏「＋新页」续页，第 2 页接第 18–34 条边，依此类推。
- 正文不写进项目状态：`state.pages.trigSummary[N]` 只保存 `meta` 与 `remark`。

对应纯计算模块是 `web/assets/calc-summary.js` 的 `trigRows()`（不碰 DOM）。表格尺寸、打印方向与表头字段在 `web/assets/app.js` 的 `TABLES` 中定义。

## 路线形式：闭合回起点 / 非闭合

底栏快捷选项或「选项 → 平差口径」可在两档间切换，设置写在 `settings.trigSummary.closed`：

| 形式 | 边的取法 | 闭合差 | 改正值 | 高程 |
| --- | --- | --- | --- | --- |
| **闭合回起点**（默认） | 最后一站的下一站接回第 1 站，边数 = 站数 | `f_h = Σ 高差平均值`，按 `K·√ΣD` 检验 | 按平距比例反号分配 | 逐条推算，最后一行闭合回起点 |
| **非闭合** | 最后一站没有回程边，边数 = 站数 − 1 | 不检验 | 全部记 0 | 仍从起点高程逐条推算到最后一点 |

非闭合路线是「开放式」观测：最后一站只测了本站往测，没有下一站返测可配。程序不会用单边值假装往返平均，直接不生成那条边，Σ 行只统计实际存在的边；精度评定写明「非闭合路线（不闭合回起点）……不分配闭合差（改正值按 0 计）……终于 X.XXX m」。

## 取数与配对

按「表一的页顺序、页内站顺序」收集所有已开始录入的测站，第 *i* 行对应第 *i* 条边：

| 列 | 取值 |
| --- | --- |
| 点名 | 本条边的终点，即下一站的站名 |
| 往测高差 | 本站**目标②**的高差（m） |
| 往测平距 | 本站目标②的水平距离（m） |
| 返测高差 | **下一站目标①**的高差（m） |
| 返测平距 | 下一站目标①的水平距离（m） |

「下一站」：闭合回起点时最后一站接回第 1 站；非闭合时最后一站不接回。闭合形式少于 3 条边不成立闭合环，非闭合形式少于 2 个测站（即 0 条边）时不成立路线，只显示原始列。

高差与表一一致：`斜距 × sin(竖直角) + 仪器高 − 棱镜高`；平距为 `斜距 × cos(竖直角)`。单盘读数或仪器高/棱镜高未填时，表一按现有值给出「暂按」结果，表六照常取该值并在注里标明，但整环会因「往返未算全」暂不平差。

## 每行的六个统计量

先按显示精度把平距、高差取到 3 位小数，再算下游，避免浮点尾数把 mm 列算成 `179.99999999`：

| 量 | 公式 | 显示 |
| --- | --- | --- |
| 平距平均值 | `(往测平距 + 返测平距) / 2` | 3 位小数，m |
| 相对误差 | `|往 − 返| ÷ 平距平均值` | 写作 `1/N`，`N = round(1/比值)`；往返完全一致记作 `1/∞` |
| 高差平均值 | `(往测高差 − 返测高差) / 2` | 3 位小数，m |
| 较差 | `(往测高差 + 返测高差) × 1000` | 整数，mm |
| 较差允许值 | 三档预设（`settings.trigSummary.sideFormula` + 系数）：`60√D`、`40√D`（`sqrt` 时为 `round(K · √D)`，`D = 平距平均值 / 1000`（km），`K = settings.trigSummary.sideLimit`），或 `0.4×S`（`linear` 时为 `round(K · S)`，`S` 为平距平均值、以 m 计，`K = settings.trigSummary.sideLinear` 默认 0.4） | 整数，mm |
| 高差改正值 | 见「闭合差分配」；非闭合一律 0 | 整数，mm |

返测高差的符号与往测相反，所以取平均用减号：两条独立观测同号时，`(往 − 返)/2` 才是同一条边的高差。

## 分页、续页与容量

- 每页固定 17 行，第 *p* 页（从 0 起）显示全局第 `p × 17 + 1` 到 `p × 17 + 17` 条边；页内 cellId 仍是 `s1-*`…`s17-*`，数据按全局行号取。
- 容量 = `17 × 页数`。闭合形式的边数超过容量、或非闭合形式（边数 = 站数 − 1）超过容量时，超出的边不显示，精度评定写明「本表 N 页共可显示 C 条边，还有 X 条未显示；补「新页」后再平差/推高程」，此时不平差。
- **Σ 行与精度评定只出现在最后一页有数据的纸上**；中间页的 Σ 留空，最后新增的空白页也不显示合计。
- 第 1 页的「起点高程」是手填的起算数据；后续页的同一格是**计算格**，自动承接上一页最后一点推算出的高程，不可编辑，提示「要改起算高程请到第 1 页」。新增页沿用当前页表头，但会去掉 `start-elev`，避免两页各说各话。
- 删除第 1 页时，若还有后续页，该页填过的起点高程会迁移到新的第 1 页，路线数据不丢。
- 底栏分页器在表六显示「第 2 / 2 页 · 第 18–34 条边」，新页/删页按钮与其他多页表一致；页数上限与表一相同（100 页）。
- 「清空本页」在表六只清当前页备注，表头与其它页保留。

## 闭合差与分配（闭合回起点）

整环算全后（见「什么时候不平差」）：

1. **闭合差** `f_h = Σ 高差平均值`（米），按已取整到 3 位小数的值累加；再换成 mm 取整，得到本表判定用的 `f_h(mm)`。
2. **闭合差允许值** `= round(K · √ΣD)` mm，`ΣD = Σ 平距平均值`（km），`K` 默认 40。
3. **改正值**按平距比例反号分配：`v_i = −f_h(mm) × D_i / ΣD`。逐条四舍五入到整数 mm；把各条取整后的余数全部加给平距最长的那条边（并列时给靠前的一条），保证 `Σv_i = −f_h(mm)` 严格成立。
4. **改正后高差** `= 高差平均值 + 改正值 / 1000`（m）。
5. **最终高程**：第 1 行从表头「起点高程」起算，之后逐行累加改正后高差，每步取到 3 位小数。闭合环最后一行的点应回到起点高程。

Σ 行显示 `Σ平距平均值`、`Σ高差平均值（= 闭合差）`、`Σ改正值`、`Σ改正后高差`；闭合环正确分配时最后一项是 `0.000`。非闭合路线下 Σ 行照常给出 ΣD 与 Σ高差（即终点与起点的高差差），Σ改正值为 0。

## 表六高程供表G 联合映射

表G「导线计算表」是表一与表六的联合映射：点号、角度、导线长取表一，高程列可选取表六。表G 抽屉里的「高程列同时取表六（只记录）」默认勾选，带入时：

- 表G 第 1 行取表六第 1 页表头的「起点高程」；
- 表G 第 *j* 行（*j* ≥ 2）取表六第 *j−1* 条边的最终高程——表六一行是一条边、表G 一行是一个点，两者错开一条边；
- 闭合导线最后一条回到首点的边，其最终高程没有对应的表G 行，不写入；非闭合路线没有这条回程边，最后一点照常取最后一条边的高程。

带入时把实际写入的个数记进开始页的 `source.heightCount`；表G 一条导线可以跨页，高程按导线全局行连续取，第 12、23… 站落在续页时照样取表六第 11、22… 条边的高程，不会在页边界断开。高程列只记录，不参与表G 的闭合差、改正数与坐标推算，也不反过来影响表六的平差。

## 什么时候不平差

出现任一条时，改正值与最终高程留空，精度评定写明原因：

- 已开始测站换算出的边数超出容量（闭合：站数 > 17 × 页数；非闭合：站数 − 1 > 17 × 页数）；
- 闭合形式已开始测站少于 3 个（不构成闭合环）；
- 非闭合形式已开始测站少于 2 个（没有边可推）；
- 有边的往返观测没算全（单盘、缺读数、缺仪器高/棱镜高）；
- `ΣD` 不大于 0。

起点高程没填或不是数字时，改正值照常显示（或非闭合的 0），最终高程留空；精度评定提示「起点高程未填」。

## 限差与「超限」

- 对向高差较差：`|较差| > 允许值` 才叫超限，**严格大于**；恰好等于允许值判合格。比较取绝对值，负的较差不能被符号吃掉。
- 对向较差允许值有三档预设，底层是 `settings.trigSummary.sideFormula` 与系数：
  - `"sqrt"` + `sideLimit = 60`（默认）：`round(60 · √D)` mm，`D = 平距平均值 / 1000`（km）；
  - `"sqrt"` + `sideLimit = 40`：`round(40 · √D)` mm，也就是此前用过的口径；
  - `"linear"`：`round(K · S)` mm，`S` 为平距平均值、以 m 计，系数 `K = settings.trigSummary.sideLinear`，默认 0.4，限 0.001–1000（步长 0.1）；等价于教材的 `0.4S` m（`S` 以 km 计）。
- `sideLimit` 限 1–10000 的整数，直接改系数可得到 60/40 以外的口径。设置里的未知公式按 `"sqrt"` 处理，缺失、非正或超出范围的系数回落到默认值；老项目没有这些键时保持原来的 60√D 口径。
- 抽屉「选项 → 平差口径」用分段控件「60√D / 40√D / 0.4×S」切档；数字框随档位切换，√D 档显示并保存 `sideLimit`，×S 档显示并保存 `sideLinear`。系数被手改成其它值时三档都不点亮，避免把自定义口径误显示成某一档。
- 闭合差：`|f_h(mm)| > 允许值` 才叫超限，同样严格大于；非闭合路线不判。允许值 `= round(K · √ΣD)` mm（`ΣD` 以 km 计），系数 `K = settings.trigSummary.closureLimit`，默认 40，限 1–10000 的整数。
- 允许值一律按**半值远离零**取整到整数 mm：先消掉二进制噪声，再进位。公式值恰好落在 `.5` 时向上取，例如 `K = 50、D = 84.1 m` 的 `50√0.0841` 数值上是 14.5，允许值取 **15 mm**，`|较差| = 15` 判合格；`K = 60、D = 855.625 m` 的 55.5 取 **56 mm**。判定与上色都用这个整数，不做「显示 15、比较却按 14.5」的两套值。
- 课程指导书若给出别的口径，切档或改系数即可，不必改代码。

打开「误差色」时：

- 相对误差按往返 `1/4000` 上色；
- 对向较差按本行的允许值上色（允许值随上面的档位走）；
- Σ 高差平均值（闭合差）按闭合差允许值上色，且只在闭合环算全时比较；
- 其余列不上色。

表四「高差闭合差」一格的误差色允许值也跟随表六当前公式（60√D、40√D 或 0.4×S）；该格只作参考色，表四本身不判超限。

分档口径与其它表一致：白 ≤1×、绿 1～2×、黄 2～3×、红 >3×；绿/黄/红同时铺整格底色并改文字颜色，详见 `docs/误差色.md`。

## 起算坐标（已移到表G）

P/T 起算坐标与 T 生成器已整体搬到表G 的「选项 → 起算数据」，表六不再有这一块：表六只负责平差、高程推算与备注。

- 旧项目里 `settings.trigSummary.coords` / `coordsPrompt` 在载入时自动迁移到 `settings.traverseCalc.coords` / `coordsPrompt`，不丢数据；新位置一旦存在即为权威。
- 表六的平差口径、改正数、闭合差与高程推算始终不使用 P/T 坐标。
- 表四表头的连接角 β1、β2 与连接边 d 是表G 解算首行的输入，表六同样不用它们。

## 精度评定行

表底一行自动生成，例如：

> f_h = +0.025 m；允许 ±0.054 m（40√ΣD，ΣD = 1.800 km）；闭合差合格；对向较差 4 条超限；闭合于 603.363 m。

- 闭合差与允许值都写出，`±` 后是允许值；
- 「合格 / 超限」按严格大于判定；
- 对向较差超限时写明条数，全部合格时写「对向较差全部合格」；
- 有起点高程时写闭合高程，否则写「起点高程未填，未推高程」。

非闭合路线的评定句改写为：

> 非闭合路线（不闭合回起点）；共 18 条边；ΣD = 1.800 km；Σ高差 = +0.031 m；不分配闭合差（改正值按 0 计）；对向较差全部合格；终于 603.394 m。

## 打印

- A4 横向，内容宽 **226 mm**（不是表四/表五的 277 mm）：表六画布 1548×1356.5，277 mm 宽会折出约 243 mm 高，超出 210 mm 纸高被裁切；226 mm 宽对应约 198 mm 高，留出上下余量。
- 多页时可选「打印本页」或「打印全部页」，全部页逐页输出；第 2 页起「起点高程」印的是承接值，纸面能看出与上一页末点一致。
- 备注与精度评定格在屏幕上和纸上都左对齐、自动折行；其余计算格居中。
- 没有真实值的格子不打印（`realOnly`），空行不会印出「待填」。

## 存储与兼容

- 项目里每页只保存 `meta`（4 项，续页通常只有 3 项）与 `remark`；正文每次渲染重算。
- 旧项目或旧 v1 文件没有 `trigSummary` 页键时，载入补一张空白页；旧 `正式版` 会忽略该页键。
- 单表信封 `kind:"table", table:"trigSummary"` 带本表各页表头与备注，以及该表设置（`closed`、`sideFormula`、较差系数、闭合差系数）；其余六表各一张空白页。导入会整体替换表六的页与设置；表六设置里不再有起算坐标。

## 待确认口径

以下默认值按课程《指标限差》与 PPT 例题设定，指导书不同就在抽屉里改：

- 对向高差较差默认 `60√D` mm（`D` 以 km 计）；可切到 `40√D`（此前用过的口径）或 `0.4×S` mm（`S` 为平距、以 m 计，等价于教材的 `0.4S` m、`S` 以 km 计）；
- 三角高程闭合差 `40√ΣD` mm（`ΣD` 以 km 计），仍固定用 √ΣD；
- 表四「高差闭合差」的误差色允许值跟随表六当前公式（`60√D`、`40√D` 或 `0.4×S`）；
- 改正值按平距比例反号分配、取整到 mm、余数给最长边（与导线闭合差的常用做法一致）；
- 表头只放一个「起点高程」，不区分已知点/待定点高程列。
