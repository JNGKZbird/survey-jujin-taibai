# 测量学实习三表 · 正式版

三张测量实习记录表合一的**离线桌面网页工具**：三表切换、逐格录入、自动计算、缺项/超限软提示、本机自动保存、JSON 导出/导入、A4 打印与多页。

表格视觉层使用 DSH 交付的 SVG 原样呈现（只读的 `..\视觉稿\`），本工具不重绘、不近似表格，只叠加输入框与计算值。

## 快速开始

1. 双击 `index.html`，用 **Edge 或 Chrome** 打开。
   - 若 `.html` 关联到了别的程序：右键 → 打开方式 → Microsoft Edge / Google Chrome。
   - 直接以 `file://` 运行，不需要服务器、安装或联网。
2. 顶部标签切换三张表；点击格子直接录入，数据自动保存在本机浏览器。
3. 填完看顶部状态（空白 / 待填 / 超限 / 已完整），或点「填写检查」逐条核对。
4. 点「打印」出 A4；多页时先选「打印本页」或「打印全部页」。

> 仅面向电脑端（Windows 桌面浏览器）。不做手机/平板布局。

## 录入方式

- **点击 / Tab** 进入格子，**Enter** 跳到下一个输入格。
- 角度为**度 / 分 / 秒三格**：
  - 度按 3 位输入（如 `068`），满 3 位自动跳分；分、秒满 2 位自动跳下一格；也可随时 Tab / Enter 前进；
  - 失焦时「分」「秒」补零（`5` → `05`）；
  - 可直接粘贴 `68°48′06″`、`68 48 6`、`68:48:6` 一类文本，自动拆分；
  - 负竖直角在**度格**输入负号（如 `-2`），分、秒填正值。
- 表二水准尺读数按 4 位数字处理：输入 `1500`；不足 4 位的纯数字在失焦时自动补前导零。
- 小数类（距离、高、斜距等）只保留数字与一个小数点，失焦去掉末尾的 `.`。
- 空表不报错；某一格/站**开始录入后**，才把未填项列为「待填」软提示。
- 所有提示**不阻断输入**，数值照常保留。

## 自动计算口径

### 表一 · 全站仪导线

- 2C = 盘左水平读数 − 盘右水平读数 + 180°（归化到 ±180°）
- 指标差 = (αR − αL) × 1800（秒），按竖直角模式换算后计算
- 竖直角模式（选项里切换，切换不清数据）：
  - **VA**：αL = L，αR = R
  - **ZA**：αL = 90° − L，αR = R − 270°
- 竖直角平均值 = (αL + αR) / 2；只有一面时给临时值
- 水平角：L = 目标② − 目标①（顺时针，负值 +360°）；R 同理；平均值跨 0°/360° 取短弧
- 斜距平均 = (L + R) / 2；只有一面时给临时值
- 平距 = 斜距平均 × cos(竖直角平均)
- 高差 = 斜距平均 × sin(竖直角平均) + 仪器高 − 棱镜高

水平角值的 L / 平均值 / R 三格全部自动算，不手填。仪器高、棱镜高未填时，高差按 0 代入并标记为临时值；补填后自动更新。

### 表二 · 三、四等水准（双面尺法）

读数单位 mm，视距与 d / Σd 单位 m。

- 后视距 = (后尺下丝 − 后尺上丝) × 0.1；前视距同理
- d = 后视距 − 前视距；Σd = 上一站 Σd + 本页/跨页逐站累加
- K + 黑 − 红（mm）：后尺、前尺分别按各站 K 计算
- 黑面高差 = 后黑 − 前黑；红面高差 = 后红 − 前红
- 第 3 行 K + 黑 − 红 = 后尺检核 − 前尺检核
- 高差中数 = [黑面高差 + 红面高差 − (K后 − K前)] ÷ 2

尺常数 K 不走手写「尺号」解析：**选项 → 尺常数（本页）** 按站选后/前尺 K，默认首站后 K₁=4.787、前 K₂=4.687，逐站交替；可逐站改或一键「按交替重置本页 K」。

右侧「备注」整列是一个文本框，每页一条，可跨行书写。

Σd 跨页连续：下一页第 1 站接着上一页最后一站的 Σd 累加。

### 表三 · 角度距离

每站 4 行：前两行盘左，后两行盘右。

- 左半测回 = 左盘目标② − 左盘目标①（顺时针，负值 +360°）
- 右半测回同理
- 半测回角值之差 = |左 − 右|（秒）
- 一测回角值 = (左 + 右) / 2（跨 0°/360° 按短弧平均）
- 目标优先**按名称跨盘配对**（右盘写成 B→A 也能算）；目标名为空或同盘重名时退回行序，并在检查面板提示。
- 「角度草图」「距离及相对误差」两列保持**留空手写**，不生成输入框、不画假图。

## 多页

- 底部翻页：`‹ 第 1/N 页 ›`；`＋新页` 在本表末尾加一页；`删除本页` 需确认。
- 「清空本页」在**选项 → 数据**里：清空当前页所有数据，保留表头、尺常数与全局设置（表二的页备注会一并清空），需确认。
- 新增页沿用当前页表头（可再改）、固定站数；表二 Σd 跨页连续（见上）。

## 打印

- 表一 **A4 横向**；表二/表三 **A4 纵向**；页面边距 10 mm（由打印样式指定）。
- 打印内容是**纸面本身**：只输出已填数值与计算结果，不输出输入框、占位符、提示色或工具栏；空白表打印为干净空白表。
- 多页表点「打印」后选择「打印本页（第 N 页）」或「打印全部 N 页」；每个应用内页面对应一张纸/一页 PDF。
- 建议在打印对话框里：纸张 **A4**、缩放 **100%（或默认）**、页边距 **默认**。表格线是矢量，无需开启「背景图形」。
- 已用无头 Edge 生成三表 PDF 核对页幅与分页；**系统原生打印对话框**（`window.print()`）请在你自己的打印机/PDF 上再目视确认一次。

## 本机保存与迁移

- 单键保存：`localStorage["survey-sheets.formal.v1"]`。
- 输入后约 380 ms 防抖保存；切换标签、隐藏页面、关闭/刷新前会强制落盘。底部显示「已自动保存 时:分:秒」。
- 数据属于**当前浏览器**，不随文件夹复制走。换电脑、换浏览器、清理浏览器数据前，请先「导出」JSON。
- 「导出」包含三表全部页与全部设置（等级、限差、K、字体、显示模式等）。
- 「导入」会**整体替换**当前三表数据，导入前有确认框；文件上限 8 MB，版本号必须为 1，页数/站数需符合本工具结构。
- 若 localStorage 中的旧数据损坏：启动时自动开空白表，并把原文备份到 `survey-sheets.formal.v1.corrupt-<时间戳>`，不会静默丢弃。
- 所有数据只在本机浏览器内，不上传网络。

## 默认值与可选项

- 表一竖直角默认 **VA**（可切 ZA）。
- 表二默认 **四等**；首站后 K₁ / 前 K₂，逐站交替。
- 表三字体默认 **宋体**（照视觉稿照片），可切 **HarmonyOS**（与表一/表二统一）；只影响表三显示与打印。
- 显示模式（选项 → 显示）：**适宽**（按窗口宽度，不超过原表宽度）/ **整页**（同时按窗口高度缩放）。
- 表一/表二的录入层字体为 HarmonyOS Sans SC（随附字体文件）。

## 自测与重新构建

在 `正式版\` 目录下：

```bat
node tests\calc-traverse.test.js
node tests\calc-leveling.test.js
node tests\calc-angle-distance.test.js
```

当前共 **40 项**计算测试（表一 13、表二 14、表三 13），全部应输出 `tests passed`。

只有 DSH 更新了 `视觉稿\` 里的 SVG/geometry 时才需要重建内联数据：

```bat
python tools\build_sheet_data.py
```

只用 Python 3 标准库；源目录 `视觉稿\` 保持只读，脚本不改动它。

## 已知边界

- 不做手机/平板；不联网；无框架、无构建步骤、无 CDN。
- 表三「角度草图」「距离及相对误差」按约定留空手写，不自动计算。
- 表二/表三的表头填写值从印刷横线的起点开始，与左侧标签距离较近（与空白表几何一致，不覆盖印刷字）。
- 表二第 1 站数据格内印有 (1)…(18) 图例：该格为空时显示图例；一旦该格有值，纸色背景盖住图例、显示数据（设计如此）。
- `file://` 下浏览器不允许 `fetch`，因此 SVG/geometry 在构建期内联；这也是必须通过 `tools\build_sheet_data.py` 更新表格的原因。
- 原生打印对话框未做自动化验证；自动化验证的是「打印 DOM + 打印 CSS → PDF」这一段。首次实机打印建议先出一份 PDF 检查页边距与分页。
- 表一默认竖直角模式为 VA；若现场记录的是天顶距，请在「选项」切换到 ZA 后再录入。
