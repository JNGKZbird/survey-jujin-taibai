# 聊天列宽：与输入框等宽、左右拖拽

> 2026-11-04 · AI 助手 · 只改前端显示层

## 需求

- 聊天区（标题栏、消息流、输入框）共用一根宽度，左右边缘严格对齐。
- 拖动输入框的左边缘或右边缘即可改宽；拖一边，另一边镜像伸缩。
- 交互语义参照可露希尔终端的 `content-column`，只取语义，不搬代码/素材。

## 一根宽度

`.agent-main` 上定义三个变量：

| 变量 | 默认 | 含义 |
|---|---|---|
| `--agent-column-w` | 760px | 用户列宽（拖拽/键盘改它） |
| `--agent-column-gutter` | 32px（≤1180 时 24px） | 左右最小留白 |
| `--agent-column-sbw` | 0px | 滚动条两侧预留总和，由 JS 量出后回写 |

- 标题栏、输入框：`min(max(var(--agent-column-w), 420px), calc(100% - gutter - sbw))`。
- 消息行：`min(max(var(--agent-column-w), 420px), calc(100% - gutter))`。
  消息区开了 `scrollbar-gutter: stable both-edges`，它的 `100%` 已经是「主列宽 − 两侧预留」，所以少减一个 `sbw`；两处上限在任意窗口下严格相等。
- 三处都靠 `margin-left/right: auto` 居中。**历史根因**：`.agent-messages > *` 原本已给了 auto 边距，但后面的 `.agent-row { margin: 0 0 24px; }` 简写把左右重置为 0，消息行实际左对齐；现在改成 `margin: 0 auto 24px`。

## 拖拽

- 输入框左右各一条 12px 隐形热区（压住边框内外各 6px）；触屏 `@media (hover:none)` 加宽到 24px。`cursor: col-resize`、`touch-action: none`，用指针捕获，移出把手也不断。
- **2×dx 推导**：列是居中的，宽度从 W 变成 W+ΔW 时，被拖的那条边只移动 ΔW/2。所以按下后按 `dx` 的 2 倍计算：右把手 `W + 2dx`，左把手 `W − 2dx`，拖拽边就能 1:1 跟住指针，另一边等量反向移动。
- 上限 = `主列宽 − gutter − sbw`；下限 420px；窗口比 420+留白还窄时先服从可用宽度，不横向溢出。
- 拖拽中只写 CSS 变量，不读布局；指针抬起/取消后写入本机偏好。简单点击把手不写盘。
- 键盘：把手 `tabindex=0`、`role="separator"`；←/→ 每次 ±20px，Shift ±60px；聚焦时把手显示一条蓝色拖拽条，`aria-valuenow`/`aria-valuemax` 同步。聚焦把手时不再点亮整个输入框的聚焦环。

## 滚动条自动隐藏

- 消息区滚动条只在用户主动滚动时出现：滚轮、触屏、PageUp/PageDown/Home/End/↑/↓、拖动滚动条都会点亮，停手约 0.9 秒后淡出。
- 流式输出触发的程序化自动滚到底不点亮；拖动期间 `scrollbarDrag` 为真时不受程序化滚动抑制。
- 使用 `::-webkit-scrollbar`（WebView2/Chromium）：槽位由 `scrollbar-gutter: stable both-edges` 始终保留，滚动条宽度恒为 9px，只变颜色透明度，列宽不跳动。
- 亮色令牌 `--agent-scroll-thumb` / `--agent-scroll-thumb-hover`，暗色单独定义；`prefers-reduced-motion: reduce` 下去掉过渡。
- 不做 hover 常显——用户明确要求“滑动时才出现”。

## 持久化

- `localStorage["survey-jujin.agentColumnWidth"]`，整数像素。
- 初始化时校验：空、非数字、≤0 回默认 760；超出记录范围夹到 420～4000。
- 窗口变窄只做视觉夹取，不覆盖偏好；窗口放大后自动回到用户设定。
- 不写 `store.json`、不进备份、不随项目导出；不改 `agent.json` 版本与 schema。

## 兼容与取舍

- `scrollbar-gutter: stable both-edges`：Chromium 94+。旧引擎忽略 `both-edges` 时退回单侧 `stable`，最多偏半个滚动条宽，不报错、不横向溢出。
- `:has()` 用来「聚焦把手时不亮整框」，Chromium 105+。不支持时只是多一圈聚焦环，功能不受影响。
- 420px 时输入卡控件会换成两行（`.agent-composer-row` 本来就 `flex-wrap:wrap`），输入框变高但不裁切；目视确认可接受。
- 没有把宽度写进项目库：这是纯显示偏好，换项目/会话不该改变阅读宽度。

## 明确不做

- 把列宽写进项目/会话、每个工作区独立宽度。
- 拖动消息区或标题栏调宽（只认输入框边缘）。
- 双击复位、吸附、预设宽度档位。
- 滚动条 hover 常显；导航轨已于 2026-11-04 按可露希尔同款重做（见 `docs/导航轨.md`），但轨道不参与列宽拖拽，也不改变 420 px 下限。
- 公式渲染（已于 2026-11-04 完成，见 `docs/公式渲染.md`）。
