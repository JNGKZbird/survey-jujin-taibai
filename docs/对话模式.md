# 对话模式：Chat 与 Work

AI 助手的输入卡左侧有一个单钮模式开关，默认 **Work**，点击后变成 **Chat**，再点回到 Work；同一时刻只显示当前模式。它决定这次会话能用哪些工具——Chat 只有联网搜索，Work 有表格工具并可选联网搜索——不是权限档位：权限（Only Read / Manual / Auto）仍只在 Work 下有意义。

## 语义

| | Chat | Work |
| --- | --- | --- |
| 工具 | 没有表格工具；联网搜索开启时**只**下发 `web_search`，关闭时无任何工具 | 读表、写表、追加空白页三个本地工具；联网搜索开启时再加 `web_search`；Only Read 只下发读表和搜索 |
| 表格 | 不读取、不写入表一/表二 | 可读可写表一/表二；先读后写，逐格校验，可撤销 |
| 权限 chip | 禁用，提示切到 Work 后可设置 | 可用 |
| 系统提示词 | 无表格工具；搜索开启时声明唯一工具是 `web_search`；要求填表时提醒切到 Work | 表格硬规则 + 工具规则 + 格 ID 字典 + 先读后写 |
| 图片 | 可发图片做问答、描述与读数核对，并可结合搜索结果；仍无表格工具 | 可发图片读表，再按权限调用表格工具；含图片轮的写入仍逐次审批 |
| 输入提示 | 问测量概念、读数与限差… | 说明要读写的表与格子… |

**Work 已能真正读表与填表**：模型调用工具时，软件读取当前工作区的表一/表二，按权限模式直接执行或先出审批卡；写入带 diff 与撤销，联立开启时表三照常同步。Chat 没有表格工具，也不会假装读过表；即使模型返回表格调用，也会被白名单拦下。

**两种模式都能收图片**（M4a/M4b）：回形针、Ctrl+V 或拖放 1–4 张 PNG/JPEG/WebP，本机压缩后直发支持视觉的主模型，或先由视觉备用模型转写。压缩后的完整图片会保存到本机附件目录，重启后仍可查看与重新生成；编辑用户消息时可增删图片。Chat 只做图片问答（可结合联网搜索）；Work 可以在看图后调用表格工具，但含图片的轮次即使 Auto 也必须逐次确认写入。详见 `docs/识图填表.md`。

**两种模式都能联网搜索**（M5）：输入卡左侧地球开关默认开启，只走 DeepSeek 官方 `https://api.deepseek.com/v1/tools/search`，沿用当前 DeepSeek Key。搜索需要提供商预设为 DeepSeek 且 Base URL 为 `https://api.deepseek.com`；Work 把它与表格工具并列下发，Chat 只下发 `web_search`，关闭时不下发任何工具。每次默认 6 条、最多 8 条，同一轮最多 2 次、一次回答最多 6 次；不抓网页正文、不自动重试、不做每次审批。搜索结果以工具卡展示来源与链接，`agent.json` 只保存来源标题 / 链接 / 站点 / 日期，不保存摘要。`docs/联网搜索.md` 有完整边界。

Chat 可回答测量学概念、计算、读数与限差等文字问题，也可以联网搜索公开资料。涉及具体表内数据时，只以用户贴出的文字为准，不猜读数，不编造观测值。首次从 Chat 切到 Work 会 toast：`Work 模式已启用：可读取与填写表一、表二。`

## 持久化

- 会话字段：`session.agentMode = "chat" | "work"`。
- 默认设置：`settings.agentMode = "work"`，记住最后一次选择；新建会话继承它。
- 旧会话、旧设置缺字段或值非法时按 `work` 处理，不迁移、不升 `agent.json` 版本。Rust 仍只校验顶层 `version === 1` 并逐字节写入。
- 切换模式调用 `STORE.touchSession()` 与 `STORE.updateSettings()`，走现有 400 ms 防抖保存。

## 填表提醒

在 Chat 里输入包含填表/读表/改表/录入/导入/核对等意图的文本时，输入卡上方出现一条非阻塞提醒：

> 填表要用表格工具，先切到 Work 模式。 [切到 Work] [×]

- 只提醒，不拦发送，草稿原样保留。
- 「切到 Work」直接切换并保持草稿；关闭后本次草稿内不再弹出。
- 清空草稿或切换模式后重新武装。
- 即使消息已经发出，Chat 的系统提示词也要求模型说明没有表格工具并提醒切到 Work，不假装读表。
- 提醒由本地正则判断（仅用于提示，不参与模型决策）；误判最多多一条可关闭的提示。

## 输出上限

- 主循环（每个工具回合）与视觉转写都显式传 `max_tokens = 393216`，即 deepseek-flash（DeepSeek-V4.1-Flash-1017）的官方最大输出 **384K**；它的上下文窗口另为 1M。
- 该值只是单次回复的上限，不预留、不预扣；模型实际生成多少 token 才计费。
- 第三方兼容网关若拒绝这个值，Rust 的 400 降级会去掉 `max_tokens`，由服务端默认值兜底；此时单轮输出可能回落到较小值。
- 真达到该上限仍会返回 `finishReason:"length"`，按现有规则不执行本轮的 tool calls，并提示重新生成或缩小任务。

## 界面

- 左栏顺序：回形针、联网地球、模式钮、权限 chip。四者在桌面统一 30 px，触屏统一 34 px；图标 17 / 18 px。回形针在桌面版、可写对话库、非生成中、图片发送未关闭时可用；联网地球在桌面版、可写对话库、非生成中且搜索可用时可切换，Work 与 Chat 通用，默认开启；不可用时点击只给原因。
- 模式钮只显示当前模式：Work 为蓝底蓝字，Chat 为软灰底灰字；`title` 与 `aria-label` 说明点击后会切到另一模式。
- Chat 下会话头徽标、会话列表元信息、顶部模块说明都显示 `Chat`；Work 下恢复显示权限模式（如 `Manual`）。
- Chat 下权限 chip 禁用；切回 Work 后恢复。
- 空状态文案按模式分开：Chat 说明可问测量概念、读数与限差，也可联网搜索，但读写表要切到 Work；Work 为「可以让我读表、填表、核对读数与限差；Only Read 下只检查不写入」。
- 暗色、窄窗、触屏沿用现有 `--agent-*` 令牌与响应式规则。

## 明确不做（本阶段）

- 不写表三/四/五/六/表G、不删页、不改设置与文件系统。
- 不做 `web_fetch` / 网页正文抓取、不做 Tavily / Brave / SearXNG、不做搜索缓存或自动重试；不给 Chat 任何表格工具，Chat 的联网搜索只提供 `web_search`。
- 不做应用内截图与后台续跑。
- 不做按会话自动切模式、不做模式级模型/人格分身。
- 不做提醒的模型侧二次确认或拦截发送。
- 不升 `agent.json` 版本、不迁移旧会话；不把图片写入项目库或导出。
