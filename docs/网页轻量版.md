# 测量学局劲工具 · 网页轻量版

## 这是什么

纯静态网页版：只保留七表填写与计算、表四/五/六汇总、表G 导线计算、联立映射、多项目、JSON 导入导出、打印/PDF、主题与误差色。**不含 AI 助手、联网搜索、图片、API Key、鸿蒙字体和 KaTeX**，打开页面不会向任何服务器发送数据。

源码仍是 `web/`；轻量版是构建产物，不是另一套代码。桌面版继续保留 Agent、鸿蒙字体与原生存储。

## 构建

在项目根目录执行：

```text
pnpm build:web
```

默认输出到 `dist-web/`，包含两种形态：

| 产物 | 用途 |
| --- | --- |
| `dist-web/index.html` + `dist-web/assets/` | 目录版，适合本地静态服务器或 GitHub / Gitee Pages |
| `dist-web/测量学局劲-轻量版.html` | 单文件版，可直接发给同学双击打开 |

当前体积约：目录版 1.1 MB 资源，单文件 1.1 MB，整个 `dist-web/` 2.2 MB。

构建脚本只清理 `dist-web/`（或 `--out` 指定的、由本工具生成过的目录），不会碰源码、`store.json`、备份或导出文件。产物目录里的 `.jujin-web-lite` 是“此目录可安全重建”的标记。

## 打开方式

- **单文件版**：双击 `测量学局劲-轻量版.html`。所有脚本和样式都在文件内，不需要网络。
- **目录版**：建议用本地静态服务器或托管地址打开，例如在 `dist-web/` 下运行 `python -m http.server 8000`，再访问 `http://127.0.0.1:8000/`。直接双击 `dist-web/index.html` 也能用，但不同浏览器对 `file://` 的资源与存储策略不一致，固定地址更稳。

## 数据保存在哪里

**HTML 文件本身不保存数据。** 数据由浏览器按“来源（origin）”写入 `localStorage`，键名是 `survey-jujin.dev.v1`（旧版 `survey-sheets.formal.v1` 会自动迁移）。

正常刷新、关掉浏览器再打开，数据通常还在；以下情况会丢失：

- 清理浏览器的“Cookie 和网站数据”、使用无痕模式、第三方清理软件、Windows 存储感知；
- 浏览器在磁盘压力下回收站点数据；
- 换浏览器、换用户配置、换设备；
- `file://` 下行为不统一：可能按文件隔离，也可能所有本地文件共用；Safari 还会限制脚本可写存储的保留期；
- `localStorage` 通常只有约 5 MB，写满后新改动无法保存（页面会提示）。

轻量版会在第一次交互时请求 `navigator.storage.persist()`。它只能降低浏览器自动回收的概率，**不能阻止手动清理**。

**唯一可靠的备份是导出 JSON。** 项目菜单 →「导出全部项目」；恢复时用「导入」或把 `.json` 文件直接拖进页面。首次打开会提示一次；如果超过 7 天没有导出，启动后会再提醒一次。

## 导入与拖放

- 「导入」按钮支持单表、七表、全部项目三种 JSON，页面会自动识别。
- 把单个 `.json` 文件拖进页面，等同于走导入流程；拖入其他类型只会提示，不会让浏览器跳走。
- 导入全部项目会整体替换当前项目库，确认框会先提醒备份；删除项目同样不可撤销。

## 多标签页

同一个浏览器里开多个标签页时，轻量版监听 `storage` 事件：另一个标签页改写了项目库，本页会提示“请刷新，避免两边互相覆盖”。MVP 不自动合并，也不加写锁；需要同时看两份时请先导出。

## 与桌面版的差异

| 能力 | 网页轻量版 | 桌面版 |
| --- | --- | --- |
| 七表、汇总、表G、联立、多项目 | 有 | 有 |
| JSON 导入导出、打印/PDF | 有 | 有 |
| 主题、误差色 | 有 | 有 |
| 自动保存 | 浏览器 `localStorage` | 本机 `store.json` + 自动备份 |
| AI 助手 / 联网搜索 / 图片 | 无 | 有 |
| 鸿蒙字体 | 无，使用系统字体 | 有 |
| 原生备份目录 | 无 | 有 |

系统字体栈为 `system-ui, "Segoe UI", "Microsoft YaHei", "PingFang SC", "Noto Sans CJK SC", sans-serif`，由构建时替换；表三里保存的 `font: "harmony"` 字段仍保留，导入导出与桌面版兼容。

## 部署

把 `dist-web/` **里面的内容**上传到静态站点根目录即可，保留 `LICENSE`。不要把整个 `dist-web/` 目录当成一级路径（否则访问地址会多一层）。单文件版也可以单独分发；许可证全文已嵌在文件末尾的 `#license-text` 中。

网页版不需要 Node、Python 或任何后端；托管方只提供静态文件。

## 打印

工具栏「打印」调用浏览器打印对话框；选择“另存为 PDF”即可导出。误差色的底色属于背景图形，若打印预览看不到颜色，请在打印对话框里勾选“背景图形/Background graphics”。
