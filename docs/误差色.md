# 误差色

顶栏「选项」左边的**误差色**按钮，把带允许误差的计算值按倍数上色，一眼看出一项误差是限差的几倍。

## 图例

课程图例原文：

> 白色数据：误差在 1 倍允许误差之内；
> 绿色数据：误差在 2 倍允许误差之内；
> 黄色数据：误差在 3 倍允许误差之内；
> 红色数据：误差超过 3 倍允许误差。

换算成 `|误差| ÷ 允许误差`：

| 倍数 | 颜色 |
| --- | --- |
| ≤ 1× | 默认纸色与墨色（图例的「白色」；白纸上的纯白底不可见） |
| > 1× 且 ≤ 2× | 绿：整格铺 `--band-2-bg`，文字 `--green` |
| > 2× 且 ≤ 3× | 黄：整格铺 `--band-3-bg`，文字 `--amber` |
| > 3× | 红：整格铺 `--band-4-bg`，文字 `--red` |

边界 2、3 归入「之内」；比较留 `1e-9` 浮点余量，`24/12` 这类整数倍不会因二进制误差跳到下一档。值无效、允许误差缺失或 ≤0 时不上色。

同一口径也用在检查面板：**超限是严格大于限差**，计算值恰好等于限差（如 2C = 20″、上限 20″）时不报超限；比较同样留 `1e-9` 余量，避免浮点噪声把「刚好 20″」算成「20.000000000015916″」而误报。

颜色同时落在**整格底色与数字文字**上：绿/黄/红档把计算格铺成对应浅色底（`--band-2-bg` / `--band-3-bg` / `--band-4-bg`），文字用同色系深色，扫一眼就能看出哪几格超了。底色画在纸面之上、印刷线之下，不改格子尺寸与印刷线；格子原有的超限描边保留，字色由四色接管（绿/黄优先于原来的琥珀色警告字）。白色档不着色，保持默认纸色。

> 2026-10-29 用户反馈「误差色不明显」后，由只换字色改为整格铺底色；图例的分档口径不变。

## 哪些值会上色

只给「本身就是误差、且已有允许误差」的计算格上色：

| 表 | 计算值 | 允许误差来源 |
| --- | --- | --- |
| 表一 | 2C | 选项 → 2C 限差（默认 12″） |
| 表一 | 指标差 x | 选项 → 指标差限差（默认 25″） |
| 表二 | 后视距 / 前视距 | 当前等级的三/四等视距限差（75 / 100 m） |
| 表二 | K+黑−红 k1 / k2 | 读数限差（2 / 3 mm） |
| 表二 | K+黑−红 k3 | 黑红面高差之差限差（3 / 5 mm） |
| 表二 | 前后视距差 d | 3 / 5 m |
| 表二 | 累计 Σd | 6 / 10 m |
| 表三 | 半测回角值之差 | 选项 → 半测回较差（默认 20″） |
| 表四 | 平距绝对误差 | 平距平均值 ÷ 4（mm），即往返 1/4000 |
| 表四 | 高差闭合差 | 跟随表六当前口径：60 × √(平距平均值 ÷ 1000)（默认，mm，D 以 km 计）、40 × √(平距平均值 ÷ 1000) 或 0.4 × 平距平均值（mm，S 为平距、以 m 计） |
| 表六 | 相对误差 | 往返 1/4000 |
| 表六 | 对向较差 | 表六当前口径：60√D、40√D 或 0.4×S（本行较差允许值，随抽屉「平差口径」的分段控件切换） |
| 表六 | Σ高差平均值（闭合差） | 闭合差允许值 K·√ΣD（默认 40√ΣD mm），只在整环算全时比较 |

表二切换三等/四等后，颜色按新限差立即重算。

不上色的值：原始读数、表一半测回角值本身、竖直角、平距与高差、表四平均值与合计、表五全部得分、表六的其余列、表G 全部（导线计算表不上误差色）。表五没有课程给的闭合差限差、表G 只在检查摘要里比较 fβ 与 K，按钮在这两张表自动隐藏；开关状态仍保留，切回其他表继续生效。

表四的「平距绝对误差 = |往−返|×1000」与「高差闭合差 = (往+返)×1000」原本只显示、不判超限，也不进入检查面板；误差色只是在这两个格子上叠加课程口径的参考色。高差闭合差的允许值与表六用同一个整数 mm（半值进位后的值），不会出现表六判合格、表四按低 1 mm 上色。

## 开关与记忆

- 顶栏「选项」左边：`误差色`，按下为开，再点关闭；开时按钮用 accent-soft 底。
- 记忆位置：localStorage `survey-jujin.errorBands`（`"1"` / `"0"`），默认关。
- 这是**本机显示偏好**，与主题同一口径：不写 `store.json`、不进任何导出/备份、切换项目不变；换电脑或清除站点数据后回到默认关。

## 打印与深色主题

- 打印跟随当前开关：开着打印就连整格底色带彩字一起印（纸仍为白纸，`print-color-adjust: exact`），关掉仍是纯黑记录表。
- 深色主题自动使用深色下的三色与半透明底（`--green` / `--amber` / `--red` 与 `--band-*-bg` 的深色变体）；深色变量只作用于屏幕，所以打印始终取浅色主题的纸与三色。

## 实现与测试

- `web/assets/error-bands.js`：`ratio(value, limit)` 与 `band(ratio)`，纯函数，不碰 DOM。
- 计算格 spec 的可选 `band(result, pageRes)` 返回比值；`app.js` 的 `bandForSpec()` 只在开关打开、值已算出时定档，异常一律不上色。
- `tests/error-bands.test.js`：13 项，覆盖正负值、空值、0 限差、1/2/3 倍边界、浮点余量、课程 2C 实例与表四两条公式；`pnpm test` 全套 273 项。
